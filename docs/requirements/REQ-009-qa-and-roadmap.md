## 浏览器验收（真实 Chromium）

- 桌面 1440×1000：登录 → 总览 → 学习路径（全栈中级）→ 微课完成 → 章节练习 5 题 → 结果与解析 → 错题队列 → JavaScript 代码题（沙箱 4/4）→ 急冲计划 → 职业规划 → 模拟面试 → 记录 → 个人设置。
- 移动 390×844：总览、学习路径、章节练习、模拟面试、记录、个人设置；`scrollWidth === clientWidth === 390`，无横向溢出。
- 面试专项：低分回答出现要点遗漏、提示和「再答一次」；重答高分触发「深入追问」；提前结束可生成报告；报告区分已答/未答，不虚构缺口。
- 控制台：修复相对时间与 ICU 时间格式导致的 hydration mismatch 后，主流程控制台错误为 0。
- 发现并修复：练习最后一题因当前选择未计入已答数而无法提交；`router.push` 后立即 `router.refresh` 引发导航竞态；移动端网格最小宽度导致 14px 横向溢出；结果页/面试报告在证据不足时仍生成“缺口”的误导性问题。
- 截图与验证脚本保存在本地 `artifacts/`、`scripts/` 临时目录，不入库；`artifacts/` 已加入 `.gitignore`。

## 安全与隔离验收

| 检查 | 结果 |
| --- | --- |
| 未登录访问 `/dashboard` | 302/重定向到 `/login?next=%2Fdashboard` |
| 未登录调用写 API | 401 |
| 跨源 `Origin` 写请求 | 403 |
| 连续错误登录 | 前 8 次 401，第 9 次 429；内存限流 |
| 会话 Cookie | `HttpOnly=true`、`SameSite=Lax`、`Path=/`；生产环境 `Secure=true` |
| 账号 A 访问账号 B 的急冲计划/面试 | 404 未找到页面，服务端按 `user_id` 查询 |
| 密码/会话 | scrypt 加盐哈希；会话令牌只存 SHA-256 哈希 |
| 代码沙箱 | iframe `sandbox` + Worker + CSP；网络被禁，3.5s 超时销毁；用户代码不上传服务端 |

## 已知限制与后续

- 全栈代码题的测试通过数由客户端沙箱上报，服务端只做形状与范围校验；它不是防作弊考试系统，适合个人练习。移动端 Kotlin 题不执行，采用参考实现 + 自评。
- `assertSameOrigin` 对缺失 `Origin` 的非浏览器请求放行，依赖 SameSite=Lax；公网部署前应改为严格拒绝并补充 CSRF Token。
- 限流为单进程内存；SQLite 为单实例文件库，不支持无状态 Serverless 横向扩展。
- 未覆盖：自动化死循环沙箱用例、HTTP 层集成测试套件、CI、部署、监控、密码找回/邮箱验证、多设备会话管理、真实大模型。
- 内容存在少量超过 80 字的要点提醒，不影响校验；后续可按教学审校精简。
- `docs/ROADMAP.md` 已规划后端、前端、iOS、数据、测试、DevOps/安全、AI 应用方向；本阶段完成后停止新增方向功能，按方向单独建 REQ。
