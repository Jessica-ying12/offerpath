# REQ-008 · 仪表盘、记录中心与移动端体验

- 状态：done
- 依赖：REQ-002 至 REQ-007
- 范围：首页聚合、记录时间线、错题队列、响应式导航与状态

> **验证记录（2026-10-21）**：`npm run typecheck`、`npm test`（34/34）、`npm run content:validate`、`npm run build` 通过；已用真实 Chromium 在 1440×1000 与 390×844 走通主流程。未勾选项若涉及未来加固（部署、CI、密码找回等），不作为本需求的交付阻塞。

## 背景

用户每天打开产品时应先看到「今天做什么」和「真实进展」，而不是课程目录。所有学习、练习、错题、代码、计划与面试必须有统一时间线；移动端要能单手完成主流程。

## 目标 / 非目标

**目标**：首页聚合今日任务、正确率、待复习错题、连续训练、最近动态与面试；记录中心可按类型筛选并查看计划/错题/面试；桌面固定侧栏、移动端顶栏 + 底部五项导航；空、错、加载状态可恢复；390px 与 1440px 可用。

**非目标**：数据可视化大屏、导出 CSV/PDF、社交动态、排行榜、推送、离线 PWA、可配置仪表盘、跨用户对比。

## 交互与页面

- `/dashboard`：问候与三个今日动作；首次未 onboarding 显示引导卡；急冲计划卡与「下一步」；错题队列前 3；方向进度环；统计卡；最近 5 条动态；最近 3 场面试。
- `/records`：四项总统计；左侧动态时间线，按「全部/学习/练习/计划/面试」筛选并显示事件数；右侧错题队列、计划进度、最近面试与空状态。
- `/practice/review`：未解决错题整组重做；空队列提供继续学习/模拟面试入口。
- 导航：`/dashboard`、`/learn`、`/sprint`、`/career`、`/interview`、`/records`。桌面 `lg`（≥1024px）显示 252px 固定侧栏；小于 1024px 显示 60px 顶栏 + 62px 底部五项（首页/学习/冲刺/面试/记录），职业规划只在桌面侧栏。
- 页面均为服务端组件；客户端表单/运行器负责 loading、错误提示与局部刷新。

## 数据与接口

- 首页由 `getDashboardData()` 直接聚合，无公开 JSON API：`lesson_progress`、`quiz_attempts`、`mistakes`、`code_attempts`、`interview_sessions`、`plans`、`activities`。
- 统计：完成微课数（全部方向）、练习次数、总正确率（所有提交的 `score/total` 之和）、未解决错题、completed 面试数、连续训练天数。
- 今日动作：取最近一份急冲计划中前 3 个未完成任务；没有计划时回退为「继续系统学习 / 复习错题 / 来一场模拟面试」。
- 记录：`listActivities` 取最近 150 条，动态只作为展示时间线；`listActivityDays` 取最近 60 个有活动的 UTC 日期计算连续天数。计划取最近 10 份，面试取最近 12 场。
- 筛选在客户端 `ActivityFeed` 内完成：`lesson_completed/solution_viewed` → 学习，`quiz_submitted/code_submitted/mistake_resolved` → 练习，`plan_created/profile_updated/account_created` → 计划，`interview_*` → 面试；没有服务端筛选参数、日期范围或 URL 状态。
- 所有查询均带 `user_id`；页面入口由 `(app)/layout.tsx` 的 `requireUser()` 保护。

## 测试计划

- 自动化：没有 dashboard/records 专项测试；`tests/services.test.ts` 覆盖部分底层查询与隔离。命令 `npm run typecheck`、`npm test` 待执行。
- 手工 1440×900：首页各区块（今日动作/急冲/错题/方向/统计/动态/面试）、侧栏当前态、记录筛选、计划/面试跳转。
- 手工 390×844：底部五项可达、输入框 16px、对话/代码编辑器/时间轴无横向滚动、长标题截断。
- 异常：断网提交显示可重试错误；空账号首页与记录页有引导；过期会话访问受保护页跳登录。

## 实现偏差与后续

- 设计文档写 `<768px` 底部导航，代码实际以 `lg`（1024px）为切换点；768–1023px 也使用移动导航，属于实现差异。
- 移动端没有「职业规划」入口，只能从学习页卡片或桌面侧栏进入；底部导航为五项而非六项。
- 记录筛选是内存过滤，刷新后回到「全部」，不能按日期/方向/关键词筛选，也没有分页或导出；超过 150 条的历史不可见。
- 连续训练按 UTC 日期计算，跨时区用户可能在本地午夜前后看到偏差；正确率是全部方向累计，不是当前方向。
- 无 `loading.tsx` 骨架屏；首屏依赖 SQLite 同步查询，大数据量时需补充分页与索引评估。
