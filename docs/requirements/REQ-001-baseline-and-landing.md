# REQ-001 · 工程基座、设计系统与公开首页

- 状态：in-progress
- 依赖：REQ-000

## 背景

需要一个可运行、可验证、视觉与交互一致的基座，让后续功能只做业务增量，不反复改基础设施。

## 目标

1. 建立 Next.js 15 + TS strict + Tailwind 工程与脚本（dev/build/typecheck/test/content:validate/seed）。
2. 固化设计令牌与基础组件：Button、Panel、Badge、Progress、Input、Textarea、PageHeader、EmptyState。
3. 公开首页：价值主张、两个方向、三种使用模式、等级说明、明确 CTA；移动优先。
4. 根布局、元信息、404 页；无外部字体/CDN 依赖。
5. 内容契约与校验脚本（供后续内容接入）。

## 非目标

- 不做登录/注册（REQ-002）。
- 不实现学习/练习页面（REQ-003/004）。
- 不接入真实 AI 或分析 SDK。

## 交互与页面

- `/`：
  - 顶部品牌 + 登录/开始使用；
  - Hero：一句话主张 + 「3 天急冲 / 12 周进阶」双 CTA + 模拟训练卡（微课→题→面试）；
  - 两个方向卡：移动端 / 全栈，带等级与内容量；
  - 「三种进入方式」：系统学、急冲、规划；
  - 「记录闭环」说明与页脚。
- 响应式：≥1024 双列 Hero，移动端单列；CTA 触达 ≥44px。
- 空会话也可见；主导航链接指向后续页面（未登录会由鉴权中间件处理）。

## 数据与接口

- 内容 JSON 通过 `trackSchema` 校验；`npm run content:validate` 检查引用与数量。
- 首页从内容模块读取方向标题/简介/等级，不硬编码课程数量描述以外的业务状态。

## 验收

- [ ] `npm install` 后可启动；首页桌面与 390px 宽无横向溢出。
- [ ] 设计令牌统一，按钮/卡片 hover、focus、disabled 可见。
- [ ] 首页文案与产品定位一致，无虚假 AI 表述。
- [ ] `npm run content:validate` 可运行（内容到位时通过）。
- [ ] 基础组件可复用，无重复样式体系。

- 浏览器 1440×900 与 390×844 截图检查。
