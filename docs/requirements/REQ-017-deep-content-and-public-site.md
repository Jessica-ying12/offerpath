# REQ-017 · 深度内容、阅读器与公网学习站

- 状态：done
- 依赖：REQ-011 / REQ-016
- 关联：`public-site/`、`docs/requirements/REQ-015-public-deployment.md`

## 背景

用户指出：平台的 90 个短知识点远不如 `f2ce7a5e` 学习包中的 48 份文档、约 3.7 万行内容详细，如果只是把 Markdown 搬到网页上，平台就没有存在价值；同时要求按需求显示内容，并重做 UI 与布局。原来的临时隧道也被明确拒绝，需要长期可访问的公网地址。

## 目标

1. 把学习包中的通用内容变成平台主内容层，而不是继续堆短卡片。
2. 平台必须比原 Markdown 多出实际能力：全文搜索、目录、清单保存、笔记、问答自测、周期复习、学习路径、按岗位/JD 重排、进度与导出。
3. 重做信息架构与阅读体验：分组导航、三栏阅读、移动端底栏/抽屉、明暗主题、阅读设置、专注模式、搜索快捷键。
4. 发布为长期公网静态站点，不使用临时隧道。
5. 明确内容与隐私边界，不把含个人项目/公司信息的简历定制文档公开。

## 内容范围

- 21 篇移动前端深度精读：HTML/CSS/JS/ES6、React/RN、小程序、工程化、项目实战、面试话术、Flutter、计算机基础、调试、代码题、TypeScript、Hybrid、测试、原生、Node、系统设计、监控安全、小程序进阶。
- 21 份问答原稿合并为 20 个精编分册，共 380 道题、758 层追问、379 个陷阱/加分提示。
- 210 道既有原创单选题（5 门课程）全部可在公开站练习。
- 内容总量约 3.37 万行。
- **排除** `简历定制/` 4 份文档：含个人经历、公司、项目指标和账号线索，不发布到公网。

## 交互与信息架构

- 总览：继续精读、三个今日动作、按目标推荐、能力地图、复习队列、最近记录。
- 学习路径：目标岗位 + JD 规则匹配 → 命中技术、优先精读、缺失核心模块 → 10 周路径与产出。
- 深度文档：层级/类型/优先级/状态筛选 + 搜索 + 推荐排序。
- 阅读器：三栏（全局导航 / 正文 / 目录+问答+笔记）、阅读进度、清单、字号行高、专注、打印、上一篇/下一篇、移动端目录抽屉。
- 面试自测：分册列表 → 题目展开（直接回答/追问/陷阱）→ 遮住答案自测 → 答上来/没答上来 → D+1/D+3/D+7。
- 题库：课程/等级/题量筛选，答题即时解析，错题重练。
- 复习：到期按文档分组、重读建议、规则说明。
- 进度：精读/问答/到期/连续学习/阅读分钟/题库正确率、分层进度、7 天活动、问答掌握、题库历史、导出/导入/清空。
- 全局：⌘K/Ctrl+K 搜索、明暗主题、移动端 5 项底栏 + 更多页。

## 技术实现

- `public-site/`：Vite + React 19 + TypeScript + Tailwind CSS。
- Markdown：`react-markdown` + GFM + raw + slug + highlight；自建 Q&A 解析器、目录、搜索索引。
- 状态：`localStorage` 单版本状态（文档进度、问答 SRS、清单、笔记、题库记录、活动、设置），支持 JSON 导出/导入。
- 路由：HashRouter。静态托管的 SPA fallback 在实际公网未生效（直接 `/docs` 返回 404），改用 `/#/` 深链，保证任意静态主机的刷新与分享可用。
- 部署：Qoder Sites 静态站点，`public-site/dist`，公开访问；无 tunnel、无后端依赖。
- 内容校验：`npm run content:validate` 检查 21/21/380、追问/陷阱数量，并扫描个人/公司信息标记；构建包再次扫描为 0。

## 非目标与偏差

- 公开站不提供账号、云同步或跨设备自动同步；数据在本机，可导出/导入。完整训练版仍保留账号与 SQLite。
- 公开站的精读内容聚焦移动前端；后端/数据库/全栈的深度文档不在本轮导入范围，210 道题库仍覆盖五门课程。
- 未公开含个人经历的简历定制文档；这是隐私边界，不是内容缺失。
- HashRouter 的 URL 形如 `/#/doc/03`，换取静态托管的可靠深链；已实测刷新与移动端。
