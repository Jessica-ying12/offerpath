# REQ-018 · 多题型题库、完整路线图与本机用户

- 状态：done
- 依赖：REQ-017
- 关联：`public-site/`

## 背景

用户反馈：题库只有单选且总量不足；题型没有按知识点区分；作答后没有清楚的纠错过程；学习分类和总览混乱；子页面缺少返回上一级；选择筛选后页面会跳回顶部；平台没有完整路线图，也没有分用户；并希望确认后端内容。

## 目标与实现

### 1. 题库按知识点覆盖多题型

- 从 21 篇精读、380 道问答生成并整理 **2276 道题**：
  - 简答 1134（主问题 + 追问）
  - 填空 247
  - 判断 247
  - 多选 60
  - 单选 588（378 道知识点单选 + 210 道五门课程单选）
- 题库首页可按知识点查看每种题型的数量，按题型、课程选择题、错题本切换。
- 每个知识点展示：简答 / 填空 / 判断 / 多选 / 单选的数量，不再只给一个总数。
- 生成题目带“基于问答生成”说明，避免把规则生成题包装成人工题库。

### 2. 作答后的纠正

- 单选：标出你的选项与正确选项，展示原因和对应知识点。
- 多选：标出正确项、你的选项、漏选数和多选数。
- 判断：显示对错、正确说法和原因。
- 填空：精确匹配，忽略空格/引号，显示正确答案和完整解释。
- 简答：展示你的回答、关键点覆盖（自动关键词匹配）、未覆盖要点、完整参考答案、易错点；作答者可对照后自评。
- 所有题型都提供“回到对应知识点”和“返回题库”；练习结束展示错题清单。
- 明确说明：本地规则匹配，不调用大模型，不是人工评分。

### 3. 分类、路线图与返回

- 新增 `/roadmap` 完整路线图：准备 → 语言 → 框架与端 → 工程化 → 项目与面试 → 进阶。
- 支持 移动前端 / React Native / 小程序 / Web 前端 / Flutter / Java 后端 六条路线。
- 每个节点给出为什么学、学完能做什么、精读/自测/题库入口和官方资料；路线参考 roadmap.sh，并附官方文档链接。
- 后端路线覆盖 Java、Spring、Redis、MySQL、测试、监控和系统设计；公开站提供课程题库与官方资料，后端深度精读保留在完整训练版。
- 深度文档库改为 L0–L4 + 面试实战分组，减少筛选标签堆叠。
- 主导航分组为：学习（总览/路线图/文档/自测）、训练（题库/复习）、成长（计划/进度/更多）。
- 一级页面统一增加返回上一级；题库练习可返回题库并恢复原滚动位置。
- 题型筛选使用本地状态，不跳页、不滚动；开始练习时才回到题目顶部。

### 4. 本机用户与总览

- 增加本机多用户：顶栏用户菜单、`/profile` 管理页、新建/切换/重命名/删除。
- 每个用户的精读、笔记、清单、问答掌握度、题库记录、目标岗位和错题独立存储；旧版本数据自动迁移到默认用户。
- 总览精简为：继续学习、今日三件事、路线位置、推荐下一步、进度、复习队列、最近记录、JD 入口。
- 明确边界：本机用户不是云端账号，不跨设备同步；提供 JSON 导出/导入。完整训练版保留账号与 SQLite。

## 非目标与偏差

- 公开站仍是静态站点；用户隔离是本机 localStorage，不是云端账号/服务端鉴权。
- 题库中的简答/填空/判断/多选由问答与原课程题目生成/编排，自动纠正为关键词/精确匹配，不宣称语义评分。
- 后端深度精读不在公开站；公开站提供后端路线、课程题库和官方资料。完整训练版包含 Java 后端课程、模拟笔试和面试。
- 未接入第三方商业题库：避免版权与接口依赖；外部站点作为资料链接，题目为原创/基于自有内容生成。
