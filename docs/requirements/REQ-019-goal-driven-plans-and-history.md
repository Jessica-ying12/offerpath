# REQ-019 · 目标驱动计划、历史返回与路线覆盖

- 状态：done（返回交互部分已由 REQ-020 替代）
- 依赖：REQ-018
- 关联：`public-site/`

> 后续变更：REQ-020 删除通用返回控件，改为可点击面包屑；计划模板也升级为按类型生成不同模块。REQ-021 将路线目录扩展到 roadmap.sh 同步的 96 条官方目录路线与 12,254 个官方主题。本文保留当时方案记录。

## 背景

用户反馈：返回按钮总是回固定父级，而不是实际上一页；首页“按目标推荐”是系统猜测，无法明确选择目标；计划的类型只有静态十周路径，不能按普通/十周/面试等需求分类，也不能删减或添加任务；路线图节点仍是平台精简版，缺少官方完整节点。

## 目标与实现

### 1. 返回实际上一页

- 新增 `HistoryBack`：`window.history.state.idx > 0` 时执行 `navigate(-1)`，否则回退到逻辑父级。
- 页面头部“返回上一页”、问答分册/自测、精读页、题库练习、路线详情均接入。
- 题库练习的“返回题库”仍保留（用于退出当前答题回到设置），同时提供历史返回。
- 实测：文档目录 → 精读页 → 返回，实际回到文档目录，而不是固定父级。

### 2. 明确选择目标

- 移除首页基于画像的“按你的目标推荐”。
- 新增目标设置：路线（26 条）+ 计划类型 + 计划名称 + 天数 + 每日分钟 + 开始日期 + 阶段 + 可选节点 + JD/简历。
- 路线详情增加“设为目标”，直接进入带该路线的计划设置。
- 首页在未设置目标时显示“设置目标”入口，不再自动猜测；设置后显示目标、任务进度、路线阶段和下一步。

### 3. 计划中心

计划模板按需求分类：

- 常规：普通计划（30 天，可改）
- 系统：十周计划（70 天，按周分组，含阶段产出）
- 冲刺：面试冲刺（14 天）
- 基础：补基础（45 天）
- 项目：项目实战（21 天）
- 定向：JD 定向（21 天，按 JD 命中技术排序）
- 长期：日常提升（30 天，低负担）

计划生成：

- 根据目标路线的阶段、节点、精读/自测/题库/课程题库资源生成任务。
- 一个节点合并为一条“学习任务”，任务内可打开精读、自测、练题子链接，避免每日任务爆炸。
- 按天分配，展示日期、任务数、预计分钟；十周计划按 10 周分组。
- 可调整阶段、天数、每日分钟、开始日期、是否包含加分节点。
- 可勾选完成/取消；可删除单个生成任务；可新增自定义任务；可清除计划。
- 计划保存在用户状态中，按本机用户隔离。

### 4. 路线覆盖

- 路线库保持 26 条独立路线，按入门/职业/技术分类；后端职业路线先选 Java/Go/Python/Node.js 语言；前端、RN、小程序、后端内容独立。
- 每条路线节点显示主题（来自精读目录或手写主题），并提供精读/自测/题库/课程题库/官方资料入口。
- 路线上增加 roadmap.sh 官方完整节点清单（24 条路线约 2265 个节点名），可搜索；绿色表示平台已有对应节点，灰色可直接打开官方。
- 仅使用官方节点名称和链接，不复制受版权保护的说明、图片或视频；本地节点说明由平台编写。
- 平台本地精读仍以移动前端 21 篇为主；后端/数据库/DevOps 等路线提供课程题库和官方资料，完整账号版仍保留对应课程与面试。

- [x] 首页显示所选目标与任务进度。

## 边界

- 计划完成是用户勾选的任务状态；精读/自测/题库进度仍独立记录，不强行把两者自动等同。
- 计划生成是本地规则算法，不调用大模型。
- 官方完整节点清单只包含名称/链接，不包含官方受版权保护的正文；详细内容需打开官方页面。
- 本机计划不跨设备同步，可随用户数据导出/导入。
