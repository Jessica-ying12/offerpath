# REQ-020 · 信息架构、计划差异化与计划驱动进度

- 状态：done
- 依赖：REQ-019
- 关联：`public-site/`

## 背景

用户反馈集中在六点：

1. 路线库仍像筛选标签堆叠，分类不直观，无法快速看出入门 / 职业 / 技术的差别。
2. 深度文档按 L0–L4 平铺，知识点、文档、章节没有层级，找不到某一章。
3. 页面仍有冗余“返回上一页”，三级页面无法通过路径直接跳转。
4. 侧栏仍显示“10 周计划”，但计划中心已经支持多种类型。
5. 不同计划类型生成结果相似；新增任务固定在顶部且只能选一个日期；计划过于死板。
6. 计划无法删除；进度页固定展示全站统计，不能为空，也不随计划变化。

## 实现

### 1. 路线库分类

- 路线库改为“四张大分类卡 + 方向筛选 + 搜索”：
  - 全部 / 入门 / 职业 / 技术，每张卡显示路线数量和用途。
  - 方向：前端、后端、移动端、全栈、语言、数据与系统、DevOps、通用，数量随分类变化。
- 筛选状态写入 URL（`/roadmap?category=career&track=移动端`），路线详情面包屑可直接回到对应分类。
- 移除首页式的“按你的目标推荐”；只有已经存在的计划才显示“当前计划”入口。
- 路线卡片直接提供“打开路线”和“用此路线做计划”，避免先跳详情再找按钮。
- 统一导航命名为“路线图库”，不再与“完整路线图”混用。

### 2. 深度文档知识树

- 新增 `src/lib/taxonomy.ts`，定义六个有序模块：
  计算机与底层基础、Web 语言与页面、框架与跨端、工程化与服务端、生产与架构、项目与面试实战。
- 文档库改为三列结构：左侧“阶段 → 模块”树，中间模块说明与文档，文档内列出章节。
- 每个模块说明“学完能做什么”，并关联对应路线。
- 每篇文档展示 4 个二级章节直达链接，支持 `/doc/:id?h=:slug`；搜索同时匹配章节名。
- 精读页面包屑为“总览 → 深度文档 → 模块 → 文档”，模块和章节均可点击；侧栏补“所属模块”文档切换。
- 文档卡片、搜索、题库、复习页中的旧 L0–L4 / 周次标签统一替换为模块名。

### 3. 移除冗余返回

- 删除全局 `HistoryBack` 与 `PageHeader back`。
- 路线、文档、计划、进度、更多、题库、问答等页面统一使用可点击面包屑。
- 仅保留“退出本次练习”“返回题库”这类结果页动作，它们不是页面返回控件。

### 4. 计划真正按类型生成

- 模板拆成七种不同的模块结构：
  - 常规：按路线阶段；每阶段含阶段复盘。
  - 10 周系统：按周生成 10 个周模块，每周有推进范围。
  - 面试冲刺：简历定点 → 技术问答 → 笔试题 → 模拟面试 → 补短板。
  - 补基础：前 60% 阶段核心节点，只保留精读/基础题/复盘，不含问答和项目。
  - 项目实战：项目拆解 → 调试专项 → 代码题 → 系统设计 → 复盘与表达。
  - JD 定向：JD 命中技术 → 岗位缺口 → 项目追问 → 全真演练。
  - 日常提升：按周组织，每天一个最小任务。
- 设置页按模板显示不同输入：面试必须填简历，JD 必须填 JD，项目/基础只显示范围说明，阶段选择只对常规/10 周/日常显示。
- 增加“计划结构预览”：生成前显示模块、任务数、类型分布、示例任务；切换类型、路线、简历或 JD 会立即变化。
- 任务分布改为按整个周期均匀展开，避免任务全挤在前几天。

### 5. 新增任务与删除

- 移除顶部固定的“第 1 天 + 标题”表单。
- 每个模块内部提供“给这个模块加一条任务”，默认日期取该模块下一条未完成任务，日期仍可调整，模块归属自动记录。
- 计划封面提供显式“删除计划”；编辑页也保留删除入口。删除后计划和计划进度一起清空，精读/问答/题库记录保留。

### 6. 计划驱动进度

- 进度页第一位展示当前计划：名称、类型、第几天、完成/剩余任务、剩余分钟、进度环。
- 模块进度、任务类型完成度、未来 7 天任务量、计划覆盖范围都从当前 `buildPlan` 结果计算。
- 没有计划时显示“计划进度为空”空状态，不把全站精读/题库数字当作计划进度。
- 全站精读、问答、正确率、最近记录保留为独立的“全站学习证据”。
- 首页“按计划做这三件”和“计划里的下一步精读”改为从当前计划任务推导；计划模块卡替代固定阶段卡。
- 侧栏和顶栏进度条只显示当前计划进度。

## 边界

- 计划仍是本地规则生成，不调用大模型；简历/JD 只做技术词匹配，不生成虚假经历。
- 公开站深度文档集中在前端/移动端；后端/Database 路线提供官方资料、课程题库与计划入口，不宣称有同等深度精读。
- 计划删除不影响精读、问答、题库等独立学习记录。
- 本机数据不跨设备同步，可导出/导入。
