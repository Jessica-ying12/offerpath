# REQ-007 · 自适应模拟面试

- 状态：done
- 依赖：REQ-003、REQ-004、REQ-005
- 范围：组题、作答、重答、追问、评分、报告、越权隔离

> **验证记录（2026-10-21）**：`npm run typecheck`、`npm test`（34/34）、`npm run content:validate`、`npm run build` 通过；已用真实 Chromium 在 1440×1000 与 390×844 走通主流程。未勾选项若涉及未来加固（部署、CI、密码找回等），不作为本需求的交付阻塞。

## 背景

技术面失败往往不是「不会」，而是讲不清项目、答不到要点、扛不住追问。模拟面试必须按简历/JD 组题，按要点给可解释反馈，低分给提示、高分追问，并把过程留成可复盘报告。

## 目标 / 非目标

**目标**：每场 5 道主问题；简历模式包含项目题，知识题来自方向题库；回答后显示分数、命中/遗漏要点、提示与参考回答；主问题 <50 分允许带提示重答一次；≥70 分插入 1 个追问；结束生成均分、优势、缺口与推荐复习；全部按用户隔离。

**非目标**：真实 LLM 面试官、语音识别/合成、视频、多人面试、限时压力面、自动评分校准、真实面试结论。

## 交互与页面

- `/interview`：选择模式（简历深挖/ JD 定向/岗位通用）、方向、等级、公司；简历与 JD 为文本域；支持 `planId` 从急冲计划带入，支持 `trackId`/`level` 预选；右侧显示最近 12 场。
- `/interview/[sessionId]`：对话流展示问题与回答；评估卡显示得分、命中/遗漏要点、建议、低分提示、可折叠参考回答；顶部显示主问题进度并可「结束并生成报告」。
- 低分时输入区显示面试官提示并按钮变为「提交第二次回答」；高分后出现「深入追问」；结束页展示均分、优势、缺口、完整问答与最多 4 个推荐微课。

## 数据与接口

| 表 | 关键字段 | 说明 |
| --- | --- | --- |
| `interview_sessions` | `id`, `user_id`, `track_id`, `level`, `mode`, `status`, `plan_json`, `summary_json`, `ended_at` | 一场会话 |
| `interview_turns` | `session_id`, `seq`, `question_id`, `parent_id`, `kind(main/retry/followup)`, `question_text`, `answer`, `score`, `feedback_json` | 逐轮记录 |

- 组题：简历按行/句切分，取 ≥18 字且含项目/负责/性能等线索的前 2 段生成项目题；`resume` 模式最多 2 道项目题，`jd` 模式有简历时 1 道，`position` 0 道；其余从同方向同等级面试库抽取，优先 JD/简历技能并做重叠惩罚与稳定抖动，最终 `mainQuestions` 截断为 5。
- 项目题固定 5 个要点（业务目标、职责边界、技术决策、取舍、量化结果）；知识题 3–5 个要点，每个要点 1–6 个别名。追问优先取该题第一个 `followUps`。
- 评分：要点覆盖 70% + 表达完整度 20%（`min(字数/140,1)`）+ 结构词 10%（因为/所以/取舍/指标等命中数/2）；字数 <20 封顶 20 分，<10 封顶 5 分；返回命中、遗漏、提示、建议、参考回答。
- 自适应：主问题首次 <50 且未重答 → `retry`（带提示，仅一次）；重答仍低则进入下一题；主问题或重答最高分 ≥70 且未追问 → 插入 `followup`；追问结束进入下一主问题。
- 报告：每道主问题取 main/retry 最高分求平均，追问分不计入；优势为均分 ≥65 的前 3 个技能，缺口为最低 3 个技能，推荐其相关微课最多 4 个；未答完时报告注明部分完成。
- API：`POST /api/interviews`（模式/方向/等级/公司/简历/JD；简历模式简历 ≥20 字，JD 模式 JD ≥20 字；无法组题 422）；`POST /api/interviews/[id]/turn`（回答 10–5000 字；问题 ID 必须等于当前待答，过期 409；已结束 409）；`POST /api/interviews/[id]/end`（至少 1 轮，否则 400；已结束直接返回已有 summary）。错误统一 `{error}`。

## 实现偏差与后续

- 「智能」是可解释规则：组题靠技能/等级/别名与哈希抖动，评分靠要点别名命中与字数/结构词，不调用大模型；表达好但换用同义词仍可能漏判。
- 追问只有每题第一个，且追问分不计入均分；报告是练习参考，不代表真实面试结论。
- 低分重答可被「直接结束面试」绕过，报告按已答部分生成；没有强制完成 5 题才能出报告。
- 当前无语音、转写、计时、摄像头、面试官记忆或跨场次能力趋势；简历/JD 为粘贴文本，不解析附件。
