# REQ-021 · 同步 roadmap.sh 完整路线目录与分类架构

- 状态：done
- 依赖：REQ-020
- 关联：`public-site/`

## 背景

用户指出路线库与 roadmap.sh 仍不一致：

1. 分类页结构不对，应该是左侧完整分类计数，右侧按分类分组的双列目录。
2. 路线只有 26 条，远少于 roadmap.sh 的公开目录。
3. 站内路线内容不完整，需要能看到每条路线的完整节点范围，而不是只给外链。

## 目标

在不复制第三方说明正文的前提下，把路线目录、分类、路线名称和主题节点范围同步到站内，并提供可用的站内详情页与计划入口。

## 实现

### 1. 官方目录数据

- 新增 `src/data/roadmap-catalog.json`：从 roadmap.sh 公开目录同步（2026-10-22）。
  - 96 条目录路线。
  - 16 个分类及官方计数：All 96、Absolute Beginners 34、Web Development 70、Frameworks 9、Languages / Platforms 23、AI & Machine Learning 26、DevOps 50、Mobile Development 9、Databases 26、Computer Science 31、Management 10、Game Development 7、Design 4、Blockchain 4、Cyber Security 11、Best Practices 5。
  - 保留官方目录的 5 个默认分组：New Roadmaps、Role Based Roadmaps、Skill Based Roadmaps、Absolute Beginners、Best Practices。
  - 保留每个分类下的子分组和路线命中关系；同一路线可归属于多个分类，与官方目录一致。
- 新增 `src/data/official-roadmap-nodes.json`：99 条可访问路线（包括分类页出现但未出现在 All 列表中的 Code Review / GraphQL / Product Design）共 12,254 个官方主题名称。
  - 主题名称作为范围索引；不复制官方说明、图片、视频或正文。
  - 平台自己的精读仍只有 21 篇移动前端深度文档，避免宣称不存在的深度内容。

### 2. 路线目录页

- 页面改为单一维度“先选路线类型、下面显示结果”：
  - 顶部路线类型：全部 96 / 职业路线 32 / 技术路线 55 / 入门路线 4 / 最佳实践 5。
  - 不再提供第二层方向下拉；分类只作为路线标签和详情元数据。
  - 结果在下方按类型分组、双列卡片展示；职业路线 32 条完整在一个选项内。
  - 同一路线在多个分组出现时按当前视图去重，All 视图卡片数为 96。
  - 额外列出 3 条未进入 All 96 的补充路线，保证没有路线缺失。
- 搜索改为全站搜索：不受当前类型限制，匹配路线名称、中文名、slug、描述、分类标签和全部主题关键词；搜索时显示“搜索结果”。
- 分类、分组和可翻译路线名使用中文；Java、React、AWS、Docker、Git、SQL 等技术专名保留英文，卡片和详情保留英文名对照。
- 移除路线库中的“对照官方目录”“官方完整图”“来源/参考官方”等外链与提示，不在目录和详情页跳转到第三方路线图。
- 平台额外维护的 3 条移动端精编路线（Java 后端、微信小程序、Hybrid）单独放在“平台精编补充”，不混入 96 条目录计数。

### 3. 路线详情与主题学习

- 26 条有站内内容的路线（23 条官方目录路线 + 3 条平台补充）继续使用平台精编阶段、精读、问答和题库。
- 其余 76 条路线由平台按“基础与路线地图 / 核心能力 / 进阶专题 / 工程与扩展”重排为 4 个阶段，**全部主题节点完整展示**，不再只取代表节点。
- 无精编路线的阶段节点改为紧凑可点击列表：
  - 每个主题显示序号、名称、核心/进阶标记。
  - 点击进入 `/roadmap/:roadmapId/topic/:topicIndex` 学习指引页。
  - 详情页同时保留可搜索的完整主题清单。
- 主题学习指引包含：
  - 所属路线、阶段、第几个主题和学习目标。
  - 最小可验证示例（常见技术使用真实代码示例；其余按领域生成工作单模板）。
  - 动手练习和 3 个自测问题。
  - 上一/下一主题、当前阶段主题列表和加入学习计划。
- 路线详情与主题页显示“相关技术专项”：当主题对应独立技术路线（如 Docker、Kubernetes、React、AWS）时，可直接进入独立路线系统学习，解决“技术包含在大类里但需要单独模块”的问题。
- 无精读节点的计划任务直接链接到站内主题学习指引，不跳第三方。

### 4. 计划路线选择

- 计划页路线选择按类型分组展示 102 个可访问路线（99 条目录相关 + 3 条平台补充），使用中文名并保留英文别名。
- 生成计划时，完整主题节点进入阶段模块，任务可打开对应主题学习指引；计划进度、模块与删除逻辑沿用 REQ-020。

## 边界

- 路线目录结构会更新；当前主题数据同步日期为 2026-10-22。
- 数据来源与归属保留在 `docs/SOURCES.md`；站内页面不提供第三方路线图跳转。
- 主题学习指引用于建立理解、示例和自测；除 26 条精编路线与 21 篇深度文档外，不宣称拥有逐篇权威正文。
- 常见技术示例按通用最小场景编写；非通用主题使用领域工作单模板，需要用户替换成自己的项目场景。
- 分类可重叠，因此分类计数之和不等于 96；以目录 96 去重计数为准。
