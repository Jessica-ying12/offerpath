# REQ-021 · 同步 roadmap.sh 完整路线目录与分类架构

- 状态：done
- 依赖：REQ-020
- 关联：`public-site/`

## 背景

用户指出路线库与 roadmap.sh 仍不一致：

1. 分类页结构不对，应该是左侧完整分类计数，右侧按分类分组的双列目录。
2. 路线只有 26 条，远少于 roadmap.sh 的公开目录。
3. 站内路线内容不完整，需要能看到每条路线的完整节点范围，而不是只给外链。

## 目标

在不复制第三方说明正文的前提下，把路线目录、分类、路线名称和主题节点范围同步到站内，并提供可用的站内详情页与计划入口。

## 实现

### 1. 官方目录数据

- 新增 `src/data/roadmap-catalog.json`：从 roadmap.sh 公开目录同步（2026-10-22）。
  - 96 条目录路线。
  - 16 个分类及官方计数：All 96、Absolute Beginners 34、Web Development 70、Frameworks 9、Languages / Platforms 23、AI & Machine Learning 26、DevOps 50、Mobile Development 9、Databases 26、Computer Science 31、Management 10、Game Development 7、Design 4、Blockchain 4、Cyber Security 11、Best Practices 5。
  - 保留官方目录的 5 个默认分组：New Roadmaps、Role Based Roadmaps、Skill Based Roadmaps、Absolute Beginners、Best Practices。
  - 保留每个分类下的子分组和路线命中关系；同一路线可归属于多个分类，与官方目录一致。
- 新增 `src/data/official-roadmap-nodes.json`：99 条可访问路线（包括分类页出现但未出现在 All 列表中的 Code Review / GraphQL / Product Design）共 12,254 个官方主题名称。
  - 主题名称作为范围索引；不复制官方说明、图片、视频或正文。
  - 平台自己的精读仍只有 21 篇移动前端深度文档，避免宣称不存在的深度内容。

### 2. 路线目录页

- 页面改为“先选择、下面显示”的目录结构：
  - 顶部路线类型选择：全部 96 / 职业路线 32 / 技术路线 55 / 入门路线 4 / 最佳实践 5。
  - 顶部方向下拉：零基础专题 34、Web 开发 70、框架 9、语言与平台 23、AI 与机器学习 26、DevOps 50、移动开发 9、数据库 26、计算机科学 31、管理 10、游戏开发 7、设计 4、区块链 4、网络安全 11、最佳实践 5。
  - 结果在下方按分组以双列卡片展示；先按类型过滤，再按方向过滤。
  - 类型写入 `?type=`、方向写入 `?category=`，支持面包屑回跳；搜索可按英文名、slug、中文名和描述过滤。
  - 同一路线在官方分类中可重叠；页面渲染时按当前筛选去重，卡片数与官方去重计数一致。
  - 额外列出 3 条“出现在官方分类页但未进入 All 96”的路线，保证没有路线缺失。
- 移除旧的“入门 / 职业 / 技术 + 方向”自造筛选。
- 分类、分组和可翻译的路线名使用中文；Java、React、AWS、Docker、Git、SQL 等技术专名保留官方英文。可翻译路线的卡片和详情保留官方英文名，便于和 roadmap.sh 对照。
- 移除外部目录大区块，目录直接在当前页完整展示。
- 平台额外维护的 3 条移动端精编路线（Java 后端、微信小程序、Hybrid）单独放在“平台精编补充”，不混入官方 96 条计数。

### 3. 路线详情

- 26 条有站内内容的路线（23 条官方目录路线 + 3 条平台补充）继续使用平台精编阶段、精读、问答和题库。
- 其余官方路线由平台按“基础与路线地图 / 核心能力 / 进阶专题 / 工程与扩展”重排为 4 个站内学习阶段；每阶段最多展示 14 个代表节点，完整主题清单可展开搜索。
- 详情页显示：
  - 官方主题总数与站内学习节点数。
  - 平台精编 / 官方节点两种明确标记。
  - 官方主题完整清单（可搜索、跳官方路线）。
  - 官方路线外链与来源日期。
  - 用此路线生成计划。
- 所有站内路线均可进入学习计划；无精读节点会生成官方资料任务，不伪造站内精读。

### 4. 计划路线选择

- 计划页路线选择改为按官方顶层分组展示 102 个可访问路线（99 条官方 + 3 条平台补充），使用官方英文名并保留中文别名。
- 生成计划时，官方节点进入阶段模块；计划进度、模块与删除逻辑沿用 REQ-020。

## 边界

- 官方路线结构会更新；当前同步日期为 2026-10-22，分类计数与主题数会随官方目录变化。
- 平台不复制 roadmap.sh 的说明正文；站内官方路线的节点描述是平台概述，详细资料通过官方链接打开。
- 26 条精编路线与 21 篇深度文档仍是平台自己的内容；其余官方路线只提供范围索引、阶段重排和计划入口。
- 分类可重叠，因此分类计数之和不等于 96；以 All Roadmaps 的 96 去重计数为准。
