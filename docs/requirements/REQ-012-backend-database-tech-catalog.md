# REQ-012 · 后端/数据库课程与技术筛选

- 状态：done
- 依赖：REQ-011

## 背景

现有只有移动端和全栈；用户需要后端这类“由很多技术组成”的方向，可选择具体技术系统学习，并能按岗位/技术筛选。仅把内容塞进全栈会让数据事实与进度语义混乱。

## 目标

1. 新增 **Java 后端**方向：Java / Spring Boot / JVM / MySQL / Redis / 高并发与可观测性，2 章/级别，共 6 章。
2. 新增 **MySQL 数据库**技术方向：建模与索引、查询与事务、复制与高可用，1 章/级别，共 3 章。
3. 新增 **计算机基础与 AI 前沿**方向：HTTP/网络、操作系统/性能、LLM 应用工程与安全，1 章/级别。
4. 每章 3 个知识点、至少 6 道练习、1 道代码题；后端面试题 15 道。
5. 新增技术库 `/library`：按岗位方向、技术（技能标签）、等级筛选；技术路径 `/tech/[skill]` 聚合所有课程中包含该技术的章节，显示顺序、进度与练习入口。
6. 课程/章节带上 `direction`、技能类别、参考来源；技术标签复用技能 ID，保证同一技术跨课程唯一。
7. 原有移动端/全栈课程纳入同一目录，不重写进度。

## 非目标

- 不在本轮完整实现 Go、iOS、Python 数据、DevOps 等方向；技术库可列出“无课程不展示”的原则，不建空壳。
- 不把 Java/Kotlin 代码在服务端执行；无法安全执行的代码题用参考实现 + 自评/对照。
- 不为每个技术复制一套页面骨架。

## 数据与接口

- 新课程 ID：`backend-java`、`database-mysql`、`cs-ai-foundations`。
- `Track.direction`：mobile / fullstack / backend / database / foundations。
- `Skill.category`：language / mobile / frontend / backend / database / cs / ai / tool。
- 章节 `references` 指向官方文档。
- 技术库读取静态内容；不新增用户数据表。
- 用户画像 `trackId` 支持新课程；数据库约束扩展（预发布阶段重建数据库，不做破坏性在线迁移）。

## 页面

- `/library`：全部课程/技术；筛选条件保留在 URL query；卡片显示级别、章数、题量、来源数与进度。
- `/tech/[skill]`：技术说明、先修关系、按等级聚合章节、开始练习/去题库。
- `/learn/[track]`：新课程复用现有目录；每级显示 2 章或 1 章。

## 验收

- [x] 后端/MySQL/计算机基础课程在技术库可见、可筛选、可进入学习与练习。
- [x] 技术路径只展示真实章节；无空壳卡片。
- [x] 新课程内容通过引用/数量/等级校验。
- [x] Java 后端有 15 道面试题并可用于模拟面试。
- [x] 现有两方向数据与进度不丢失（本地预发布库可重建，需记录）。
