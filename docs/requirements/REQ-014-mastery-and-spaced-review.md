# REQ-014 · 掌握度、周期复习与学习报告

- 状态：done
- 依赖：REQ-004 / REQ-013

## 背景

“学完一遍”不等于掌握；用户要求学习后按周期复习，确认掌握才能标记。当前只有进度、一次成绩和错题，没有复习计划或掌握状态。

## 掌握定义

章节需要同时满足：
1. 本章 3 个知识点全部完成；
2. 章节练习 ≥ 60%；
3. 至少 3 次通过间隔复习（D+1、D+3、D+7，复习 ≥ 80%）。

状态：`学习中 → 待复习 → 复习中 → 巩固中 → 已掌握`。复习失败不升级，次日再复习；错题独立进入错题队列。

## 数据

- `chapter_mastery(user_id, chapter_id, track_id, stage, review_count, next_review_at, last_review_at, updated_at)`。
- `review_attempts`：每次复习的范围、成绩、逐题结果、时间。
- 提交章节练习时更新掌握度：通过 → 待复习（D+1）；未通过 → 保持学习中，并提示补知识点。
- 复习通过：复习次数 +1；下一次间隔 3 天 / 7 天；第 3 次通过 → 已掌握。
- 复习失败：次日再练，记录失败，不降低已通过的知识点进度。
- 所有时间以服务端 UTC 记录，页面按本地时区显示日期。

## 页面

- `/review`：今日到期、逾期、未来 7 天复习；开始复习（从该章题库抽 5–8 题）；通过后展示下一复习日。
- 章节目录/首页：显示每个章节掌握状态和下次复习日。
- `/reports`：掌握分布、待复习/已掌握数量、按技术/等级的薄弱项、每周学习/练习/面试/笔试数据、最近复习记录。
- 首页：今日三件事中加入“复习到期”，统计卡显示待复习和已掌握。

## 验收

- [x] 只完成知识点但没有通过章节练习 → 不能算待复习/掌握。
- [x] 章节练习通过后 1 天出现在复习队列；失败次日再次出现。
- [x] 三次复习通过后才变为“已掌握”，学习报告与首页一致。
- [x] 跨用户数据隔离；刷新/重复提交不重复记录。
- [x] 时间边界（到期、逾期、未来 7 天）有测试。

## 非目标

- 不做艾宾浩斯全套算法调参、通知推送、跨设备提醒。
- 不用“看过页面”自动标记掌握。
