# 职跃 OfferPath · 页面与交互设计

## 1. 设计定位

关键词：**专注、可执行、像训练舱而非资料库**。用户打开后 5 秒内知道「今天做什么」，而不是浏览课程超市。

- 视觉基调：深墨绿黑底 + 荧光青柠强调色，少量薄荷与琥珀作为状态色。
- 质感：细边框、网格/点阵背景、等宽小标签（如 `01 / 学习`）、克制的圆角与阴影。
- 信息层级：大标题短句；每屏一个主动作；进度与结果用数字直给。
- 禁止：大面积紫蓝渐变、通用 SaaS 插图、无意义动效、假数据装饰。

## 2. 设计令牌

| Token | 值 | 用途 |
| --- | --- | --- |
| `ink-950/900` | #070B0A / #0A100E | 页面背景 |
| `ink-800/700` | #111A17 / #17231F | 卡片、浮层 |
| `line` | rgba(255,255,255,.08) | 描边/分隔 |
| `paper` | #F1F6F2 | 主文字 |
| `muted` | #93A69C | 次级文字 |
| `lime` | #C9F56A | 主动作、当前状态、进度 |
| `mint` | #79E3C1 | 正确、完成 |
| `amber` | #FFC46B | 提醒、待复习 |
| `coral` | #FF8C7A | 错误、危险 |

- 字体：系统无衬线（Inter/PingFang SC），代码与编号用 monospace。
- 标题字距收紧（-0.02em~-0.04em）；正文 14–16px，行高 1.7。
- 圆角：卡片 18px，按钮 12px，Pill 999px。
- 阴影仅用于浮层/主卡片，避免满屏发光。

## 3. 信息架构

```
公开
├─ /                     落地页：价值主张、两个方向、模式说明
├─ /login                登录（含演示账号）
└─ /register             注册
应用（需登录，侧边栏/底部导航）
├─ /dashboard            今日任务、进度、错题、动态
├─ /learn                方向选择 + 最近学习
│  └─ /learn/[track]     等级切换、章节目录、进度
│     └─ /learn/[track]/[chapter]/[atom]  微课
├─ /practice             练习入口/待复习
│  ├─ /practice/chapter/[chapter]         章节练习（5 题 + 代码题入口）
│  ├─ /practice/code/[challenge]          代码题
│  └─ /practice/review                    错题重做
├─ /sprint               急冲表单 + 历史
│  └─ /sprint/[plan]     匹配分析 + 每日任务
├─ /career               规划表单 + 历史
│  └─ /career/[plan]     阶段路线图
├─ /interview            面试设置 + 历史
│  └─ /interview/[session]  对话式面试 + 报告
├─ /records              全部记录（筛选）
└─ /profile              资料、目标、简历/JD、退出
```

## 4. 关键流程

### 4.1 首次使用
注册 → 选择方向（移动端/全栈）→ 选择等级（初级/中级/高级，含一句差异说明）→ 可选填写目标岗位/公司 → 进入首页（首次显示引导卡，不阻塞学习）。

### 4.2 微课 → 章节练习
目录点击知识点 → 微课页展示「先记结论」→ 关键点 → 例子 → 坑 → 面试表达 →「完成本节，下一节」。完成本章 3 节后，练习入口高亮 → 一题一屏，选择即锁定？否，选择后点「提交本题」→ 立即显示正误、解析、要点；进入下一题；5 题结束显示成绩、错题列表、「重做错题 / 再做一遍 / 去代码题」。

### 4.3 急冲
表单（方向、等级、周期、目标公司、简历、JD）→ 校验（简历/JD 至少填一项且 ≥ 30 字；冲刺推荐两者都填）→ 生成 → 结果页顶部「匹配诊断」：命中技能、缺口技能、依据；下方按天任务卡，包含知识点、练习、代码题、模拟面试；点击任务跳转；顶部显示计划完成度。

### 4.4 职业规划
三步向导（方向与等级 → 周期与目标 JD → 确认）→ 路线图：左侧阶段时间轴，右侧技能覆盖与任务；每阶段有验收标准（完成章节/正确率/完成一次模拟面试）。

### 4.5 模拟面试
设置（方向/等级/模式：基于简历/基于 JD/通用；简历/JD 文本）→ 进入对话：面试官问题、输入框、字数提示；提交后卡片显示得分环、命中/遗漏、引导语、参考回答折叠；低分出现「带着提示再答一次」，高分出现「继续追问」；顶部进度 x/5，可随时结束；完成显示报告与推荐复习。

### 4.6 错题重做
记录页/首页进入 → 逐题重做（不显示答案）→ 提交后显示解析 → 答对标记已解决；答错累计次数。全部完成显示「本次解决 n 题」。

## 5. 组件清单

- `AppShell`：桌面固定侧栏（品牌、导航、当前方向/等级、账号菜单）；移动端顶栏 + 底部五项导航。
- `PageHeader`：眼标（eyebrow）、标题、说明、右侧动作。
- `Button`：primary（lime 底黑字）、secondary（描边）、ghost、danger；尺寸 sm/md/lg；focus-visible 清晰。
- `Panel`：描边卡片，可带 `data-tone`（默认/强调/警示）。
- `Badge` / `LevelTabs` / `ProgressBar` / `Stat` / `EmptyState`。
- `QuizRunner`：单选、提交、解析、进度；键盘可操作。
- `CodeRunner`：编辑器 textarea + monospace、语言标签、运行/自评、测试结果列表、参考实现折叠。
- `InterviewRoom`：对话流 + 评估卡 + 输入区。
- `ActivityList`：图标 + 标题 + 时间 + 结果。
- `Toast`：轻量操作反馈（保存、错误）。

## 6. 响应式

| 断点 | 布局 |
| --- | --- |
| < 768px | 单列；底部导航 5 项（首页/学习/冲刺/面试/记录）；顶部仅品牌与等级；卡片内边距压缩；表格改卡列 |
| 768–1024 | 内容单列 + 顶部导航；双列统计卡 |
| ≥ 1024 | 侧边栏 248px + 主内容；内容最大宽 1200px；两列信息布局 |
| ≥ 1440 | 主内容留白增加，学习页可三栏（目录/正文/提示） |

触控目标 ≥ 44px；输入框使用 16px 字号避免 iOS 放大；避免仅 hover 才出现的信息。

## 7. 状态与文案

- 加载：结构化骨架/按钮内 loading，不用全屏转圈。
- 空：解释为什么空 + 一个主动作（如「生成第一份急冲计划」）。
- 错误：人话 + 可执行动作；不显示堆栈。
- 成功：用结果代替「操作成功」（如「已完成 3/5，错题已加入复习」）。
- 规则引擎结果标注「基于简历与 JD 关键词匹配，可解释、非大模型生成」，避免误导。
- 面试评分说明基于要点覆盖与表达完整度，仅供练习参考。

## 8. 可访问性

- 语义化标题层级；表单 label 显式关联；错误 `aria-describedby`；对话区 `aria-live="polite"`。
- 对比度 ≥ 4.5:1；焦点样式 2px lime；所有图标按钮有 `aria-label`。
- 动效尊重 `prefers-reduced-motion`；无自动播放/闪烁。
