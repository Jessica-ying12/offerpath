# 方向规划

> 本文只做后续方向规划；已实现范围以代码、`data/` 与 `docs/requirements/` 为准。

## 已实现（v2）

- 5 门课程：移动端、全栈、Java 后端、MySQL、计算机基础与 AI。
- 30 章 / 90 个无视频知识点 / 210 道原创单选题 / 30 道代码题。
- 技术库与跨课程技术路径、题库筛选练习、限时模拟笔试。
- 章节掌握度 + D+1/D+3/D+7 周期复习 + 学习报告。
- 急冲计划、职业规划、自适应模拟面试、统一记录与用户隔离。
- Docker 单实例部署与临时公网预览。
- **公开深度学习站**：21 篇精读 / 380 道问答 / 2276 道五题型题库 / 26 条入门·职业·技术路线 / 本机多用户，公网静态部署；含个人经历的简历定制文档不公开。

## 下一步候选（有真实需求再做）

1. **前端方向**：HTML/CSS、浏览器渲染、React 深入、性能与可访问性；与全栈共享部分前端技能，但不重复计进度。
2. **测试与质量方向**：测试金字塔、契约测试、E2E、性能测试与故障演练。
3. **安全方向**：Web 安全、认证授权、依赖与供应链、LLM 应用安全；与现有章节交叉引用，不复制内容。
4. **数据方向**：SQL 进阶、数据建模、数据管道；需要单独的课程目标与练习形态。
5. **移动端深化**：Compose 性能、架构演进、跨端取舍；以真实 Android 工程问题为素材。
6. **账号能力**：密码找回、邮箱验证、会话设备管理；涉及邮件服务，需单独需求。
7. **持久公网托管**：在持有域名与主机后，补 CI/CD、备份恢复演练、监控与日志。
8. **可选 AI 能力**：若引入大模型，必须保留可解释规则作为兜底，明确标注生成内容，并做提示注入与隐私防护；不得把规则引擎包装成 AI。

## 明确不做

- 视频课程、直播、社区、排行榜、支付与会员。
- 没有内容支撑的空课程、假进度、假 AI 评分。
- 为凑数量复制题目或使用无来源的「面经」。
