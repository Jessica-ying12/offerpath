## Q1. ES6 有哪些新特性？

**直接回答：**

> 主要分几类：变量 `let/const`、箭头函数、默认/剩余/展开、解构、模板字符串、对象简写/计算属性、class/extends、Promise、模块 `import/export`、Map/Set/WeakMap、Symbol、迭代器/生成器、Proxy/Reflect。

**追问 1：你项目里最常用哪些？**

> 解构、箭头函数、模板字符串、模块、Promise/async-await、可选链/空值合并、Map/Set，以及 class/私有字段。

**追问 2：ES6 和 ES2015 是什么关系？**

> 同一个东西。ES6 是 ES2015 的俗称，之后每年发布一版，所以有 ES2016、ES2017……现在统称 ES6+。

**陷阱/加分：**

- 不要只背名词，挑 2-3 个能讲原理的展开。
- 新语法不等于所有浏览器都支持，要看构建配置。

## Q2. `let/const` 和 `var` 的区别？TDZ 是什么？

**直接回答：**

> `var` 函数作用域、提升且初始化为 undefined、可重复声明；`let/const` 块级作用域、有 TDZ、不能重复声明。`const` 不能重新赋值，但对象内容可以改。TDZ 是从块开始到声明语句之间，变量存在但不能访问。

**追问 1：为什么会有 TDZ？**

> 为了让块级作用域更安全，避免在声明前使用变量；它让 `let/const` 的初始化顺序更可预测。

**追问 2：`const` 对象为什么能改？**

> `const` 保证绑定不变，不保证值不可变；要冻结对象用 `Object.freeze`，但它是浅冻结。

**陷阱/加分：**

- `typeof` 一个 TDZ 变量也会报错。
- 循环里 `let` 每次迭代创建新绑定。

---

## Q3. 箭头函数和普通函数的区别？

**直接回答：**

> 箭头函数没有自己的 this，取定义时外层作用域的 this；没有 arguments，用 rest 参数；不能 new，没有 prototype；不能用作生成器。适合回调和短函数，不适合对象方法和需要动态 this 的场景。

**追问 1：为什么对象方法不要用箭头函数？**

> 箭头函数的 this 不指向对象，而是外层作用域，`obj.method()` 里拿不到 obj。

**追问 2：箭头函数能使用 `arguments` 吗？**

> 不能，它没有自己的 arguments；它会拿到外层函数的 arguments，容易出错，建议用 `...args`。

**陷阱/加分：**

- 箭头函数不能被 call/apply/bind 改变 this。
- 返回对象要加括号：`() => ({ a: 1 })`。

---

## Q4. 解构赋值怎么用？默认值什么时候生效？

**直接回答：**

> 数组按位置解构，对象按属性名解构；支持重命名、嵌套、剩余、默认值。默认值只在值严格等于 `undefined` 时生效，`null` 不会触发默认值。

**追问 1：函数参数解构不传参数会怎样？**

> 直接解构 undefined 会报错；要写 `function f({ a } = {}) {}` 给参数默认值。

**追问 2：怎么交换两个变量？**

> `[a, b] = [b, a]`，不需要临时变量。

**陷阱/加分：**

- 对象解构的属性名要和源对象一致，除非重命名。
- 解构可以用于函数返回多个值。

---

## Q5. 模板字符串有什么好处？什么是标签模板？

**直接回答：**

> 模板字符串用反引号，支持 `${}` 插值、多行文本、表达式，不用字符串拼接。标签模板是 `tag\`...\`` 的形式，函数接收字符串片段和插值，可以做转义、国际化、样式处理。

**追问 1：模板字符串能嵌套吗？**

> 可以，但可读性差，复杂逻辑建议抽函数。

**追问 2：标签模板用在哪里？**

> styled-components 的 `styled.div\`...\``、国际化、HTML 转义、SQL 模板等。

**陷阱/加分：**

- 模板字符串里的表达式会立即求值。
- 不要把用户输入直接拼进 innerHTML 模板。

---

## Q6. 默认参数、剩余参数、展开运算符有什么区别？

**直接回答：**

> 默认参数给形参兜底，只有 undefined 才用默认值；剩余参数把多个实参收集成真数组；展开运算符把数组/对象拆开，用于函数调用、数组/对象合并。展开是浅拷贝。

**追问 1：`...` 在函数参数和调用里分别是什么？**

> 函数声明里的 `...args` 是剩余参数；调用/数组/对象里的 `...x` 是展开。

**追问 2：对象展开会拷贝原型属性吗？**

> 不会，只拷贝可枚举的自有属性。

**陷阱/加分：**

- 剩余参数必须是最后一个参数。
- 展开大数组/大对象有性能开销。

---

## Q7. ES Module 怎么用？和 CommonJS 的区别？

**直接回答：**

> 用 `export` 导出、`import` 导入，支持命名导出、默认导出、动态 `import()`。和 CommonJS 的区别：ESM 编译时静态分析、异步加载、导出实时绑定、支持 tree shaking 和顶层 await；CommonJS 运行时加载、导出值拷贝。

**追问 1：默认导出和命名导出的区别？**

> 默认导出每个模块一个，可以随便命名；命名导出可以有多个，导入时必须用对应名字或 `as` 重命名。

**追问 2：动态 import 有什么好处？**

> 返回 Promise，可以按需加载/代码分割，React 路由懒加载就用它。

**陷阱/加分：**

- ESM 顶层 this 是 undefined。
- 模块默认严格模式。
- 循环依赖时可能拿到未初始化的绑定。

---

## Q8. class 和构造函数有什么区别？`extends/super` 做了什么？

**直接回答：**

> class 是原型继承的语法糖，但更严格：必须 new、内部自动严格模式、方法不可枚举、声明有 TDZ。`extends` 建立原型链，`super` 调用父类构造函数或父类方法；constructor 里必须先 super 才能用 this。

**追问 1：class 里的私有字段怎么写？**

> 用 `#field`，只能在类内部访问；私有方法同理。它不是真正的运行时私有（旧方案用 WeakMap），但现代 JS 已支持。

**追问 2：静态方法和静态字段呢？**

> 用 `static` 定义在类本身上，不在实例上；静态代码块 `static {}` 用来做类初始化。

**陷阱/加分：**

- class 方法不可枚举，构造函数原型方法可枚举。
- 箭头函数不能作为构造函数，class 也不能不用 new。

## Q9. Map、Set、WeakMap、WeakSet 的区别？

**直接回答：**

> Map 是键值对，键可以是任意类型，保持插入顺序；Set 是值的集合，自动去重。WeakMap/WeakSet 的键必须是对象，弱引用，不可遍历，键没有其他引用时可被回收，常用来存私有数据/缓存。

**追问 1：Map 和普通对象怎么选？**

> 键不是字符串、需要顺序、频繁增删、需要 size 时用 Map；普通对象适合简单配置和 JSON 数据。

**追问 2：WeakMap 为什么能避免内存泄漏？**

> 它对键是弱引用，键对象没有其他引用时可以被 GC 回收，不会因为缓存一直持有对象。

**陷阱/加分：**

- WeakMap 不可遍历，也不支持 clear/size。
- Set 判断对象去重是按引用，不是按内容。

---

## Q10. Proxy 和 Reflect 是什么？Vue3 为什么用 Proxy？

**直接回答：**

> Proxy 可以拦截对象的 get/set/has/delete 等操作；Reflect 提供操作对象的默认行为，常和 Proxy 配合保持默认语义。Vue3 用 Proxy 做响应式，因为能监听新增/删除属性、数组索引和 length，不像 Vue2 的 `Object.defineProperty` 需要递归和特殊处理。

**追问 1：Proxy 有什么性能代价？**

> 每次属性访问都要走拦截器，比普通对象慢；Vue3 通过缓存和依赖收集优化。

**追问 2：Proxy 能代理函数吗？**

> 能，`new Proxy(fn, { apply(target, thisArg, args) {} })` 可以拦截调用。

**陷阱/加分：**

- Proxy 的 set 拦截器在严格模式下必须返回 true，否则报错。
- Proxy 不能直接代理原始值。

---

## Q11. 可选链和空值合并的区别？有什么坑？

**直接回答：**

> 可选链 `?.` 在左边是 null/undefined 时返回 undefined，不报错；空值合并 `??` 只在左边是 null/undefined 时取右边。`||` 在左边是假值（0、''、false）时就取右边。

**追问 1：`obj?.a.b` 和 `obj?.a?.b` 有什么区别？**

> 前者只对 obj 做可选链，如果 obj.a 是 null，再访问 .b 仍然报错；后者每一层都安全。

**追问 2：`0 ?? 10` 和 `0 || 10` 分别是什么？**

> `0 ?? 10` 是 0；`0 || 10` 是 10。

**陷阱/加分：**

- 可选链不能用在赋值左侧。
- `??` 不能和 `||`/`&&` 不加括号混用。

---

## Q12. Promise 和 async/await 在 ES6 里怎么用？

**直接回答：**

> Promise 用 `new Promise((resolve, reject) => ...)` 创建，`.then` 处理成功，`.catch` 处理失败，`.finally` 收尾。async 函数返回 Promise，await 等待 Promise 完成，让异步代码像同步；错误用 try/catch。

**追问 1：多个请求怎么并行？**

> `Promise.all([p1, p2])`；需要保留部分失败结果用 `allSettled`。

**追问 2：async 函数里 return 一个值，调用方怎么拿？**

> 调用方也要 await 或 `.then`，因为 async 永远返回 Promise。

**陷阱/加分：**

- forEach 里的 async 不会被外层 await。
- await 会让出主线程，但不是多线程。

---

## Q13. Babel 和 polyfill 的区别？

**直接回答：**

> Babel 负责语法转换，把箭头函数、class、可选链等转成旧浏览器能跑的代码；但像 Promise、Array.prototype.includes 这种新 API，语法转换解决不了，需要 core-js 这样的 polyfill 在运行时补齐。

**追问 1：`@babel/preset-env` 怎么知道要转哪些？**

> 根据 browserslist 的目标浏览器，结合 `useBuiltIns: 'usage'` 按需引入 core-js。

**追问 2：polyfill 会全量引入吗？**

> 可以全量，也可以按需；按需体积更小，但要注意兼容性和副作用。

**陷阱/加分：**

- Babel 不处理新 API，只处理语法。
- polyfill 会污染全局（core-js 3 可以按需/不污染）。

---

## Q14. 什么是 tree shaking？条件是什么？

**直接回答：**

> 打包时删除没有被使用的 ESM 导出代码。依赖静态的 import/export、生产模式、`sideEffects` 配置正确；CommonJS 运行时加载，通常无法可靠 tree shaking。

**追问 1：`sideEffects: false` 是什么意思？**

> 告诉打包工具这个包的模块没有副作用，可以安全地删除未使用的导入；如果有 CSS/全局初始化，要单独标注。

**追问 2：为什么 `import './style.css'` 可能被删？**

> 如果 package 声明 `sideEffects: false`，打包工具可能认为这个导入没副作用而删掉；所以要配置 `sideEffects: ["*.css"]`。

**陷阱/加分：**

- tree shaking 只删除未使用的导出，不删除模块内的副作用。
- 动态 import 的代码分割是另一回事。

---

## Q15. 顶层 await 是什么？有什么限制？

**直接回答：**

> ES2022 特性，允许在 ES Module 顶层直接写 await，模块会等异步完成后再执行依赖它的模块。只能用于 module，不能用于 CommonJS 和普通 script。

**追问 1：顶层 await 会阻塞页面吗？**

> 会阻塞依赖它的模块执行，但不阻塞其他独立模块；浏览器会异步加载模块，不会同步阻塞 HTML 解析。

**追问 2：什么场景适合用？**

> 模块初始化需要异步资源，比如加载配置、初始化数据库连接、动态加载语言包。

**陷阱/加分：**

- 不要在顶层 await 里做很慢的操作，会影响依赖它的模块。
- 循环依赖 + 顶层 await 容易死锁。

## Q16. ES2020-ES2024 有哪些常用新特性？

**直接回答：**

> ES2020：可选链、空值合并、BigInt、`Promise.allSettled`、动态 import、`globalThis`。ES2021：逻辑赋值、`replaceAll`、`Promise.any`。ES2022：顶层 await、class 字段/私有字段、`at()`、`Object.hasOwn`。ES2023：`findLast`、`toSorted/toReversed/toSpliced/with`。ES2024：`Object.groupBy`、`Promise.withResolvers`。

**追问 1：`toSorted` 和 `sort` 的区别？**

> `sort` 修改原数组，`toSorted` 返回新数组，不改变原数组。

**追问 2：`Object.groupBy` 怎么用？**

> `Object.groupBy(list, item => item.type)`，返回按 key 分组的对象。

**陷阱/加分：**

- 新 API 要注意浏览器/Node 兼容性。
- ES2024 的部分特性还比较新，项目里用之前查兼容表。

## Q17. 迭代器和生成器是什么？

**直接回答：**

> 可迭代对象实现了 `Symbol.iterator`，返回一个迭代器，迭代器有 `next()`，返回 `{ value, done }`。生成器用 `function*` 和 `yield`，可以暂停/恢复，适合惰性序列和异步流程。

**追问 1：`for...of` 的原理？**

> 调用对象的 `Symbol.iterator` 拿到迭代器，不断 `next()` 直到 done 为 true。

**追问 2：生成器能做什么？**

> 惰性生成无限序列、自定义迭代器、async/await 的前身、状态机。

**陷阱/加分：**

- 普通对象默认不可迭代，要自己实现 `Symbol.iterator`。
- 生成器函数调用后不会立即执行，第一次 next 才开始。
