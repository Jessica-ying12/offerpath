## 1. 云开发

微信云开发提供：

- 云数据库（文档型）。
- 云存储（文件）。
- 云函数（Node.js）。
- 云调用（微信 API）。

### 1.1 初始化

```js
// app.js
App({
  onLaunch() {
    wx.cloud.init({
      env: 'your-env-id',
      traceUser: true,
    });
  },
});
```

### 1.2 数据库

```js
const db = wx.cloud.database();

// 查询
const res = await db.collection('goods')
  .where({ status: 1 })
  .orderBy('createdAt', 'desc')
  .limit(20)
  .get();

// 新增
await db.collection('goods').add({
  data: { title: '耳机', price: 199, status: 1 },
});

// 更新
await db.collection('goods').doc('id').update({
  data: { price: 189 },
});
```

### 1.3 云函数

```js
// cloudfunctions/login/index.js
const cloud = require('wx-server-sdk');
cloud.init({ env: cloud.DYNAMIC_CURRENT_ENV });

exports.main = async (event, context) => {
  const wxContext = cloud.getWXContext();
  return {
    openid: wxContext.OPENID,
    appid: wxContext.APPID,
  };
};
```

```js
const { result } = await wx.cloud.callFunction({
  name: 'login',
  data: {},
});
```

### 1.4 优缺点

优点：

- 不用自己搭服务器/数据库。
- 和微信登录/支付/云调用集成好。
- 适合中小项目/快速上线。

缺点：

- 绑定微信生态，迁移成本高。
- 复杂查询/事务/性能不如自建后端。
- 冷启动/配额/费用要评估。

## 2. 订阅消息

### 2.1 流程

```text
1. 小程序申请模板，拿到 tmplId
2. 用户点击按钮，调用 wx.requestSubscribeMessage
3. 用户同意后，后端调用微信接口发送订阅消息
4. 用户点击消息进入小程序
```

```js
wx.requestSubscribeMessage({
  tmplIds: ['TEMPLATE_ID_1'],
  success(res) {
    if (res['TEMPLATE_ID_1'] === 'accept') {
      // 通知后端记录订阅，后续发送
    }
  },
  fail(err) {
    console.error(err);
  },
});
```

注意：

- 必须在用户点击事件里调用。
- 一次最多 3 个模板（以官方为准）。
- 用户拒绝后不要反复弹。
- 发送由后端调微信接口，需要 access_token。

## 3. 分享、二维码、场景值

### 3.1 分享

```js
Page({
  onShareAppMessage() {
    return {
      title: '好物推荐',
      path: '/pages/detail/detail?id=1&from=share',
      imageUrl: '/images/share.png',
    };
  },

  onShareTimeline() {
    return {
      title: '好物推荐',
      query: 'id=1&from=timeline',
    };
  },
});
```

### 3.2 小程序码

- 服务端调 `wxacode.getUnlimited` 生成小程序码。
- `scene` 参数有长度限制，适合传短 ID。
- 用户扫码进入 `onLoad(options)`，`options.scene` 需要 decode。

```js
Page({
  onLoad(options) {
    if (options.scene) {
      const scene = decodeURIComponent(options.scene);
      // scene 里是自己拼的短参数
    }
  },
});
```

### 3.3 场景值

```js
const { scene } = wx.getLaunchOptionsSync();
```

常见场景：扫码、分享、搜索、公众号菜单等；用于渠道统计/来源判断。

## 4. 隐私与授权

### 4.1 隐私协议

- 在公众平台配置隐私保护指引。
- 涉及用户信息（头像、手机号、位置、相册）要告知用途。
- 用 `wx.requirePrivacyAuthorize` 触发隐私授权（按官方最新 API）。

```js
wx.requirePrivacyAuthorize({
  success() {
    // 用户同意
  },
  fail() {
    // 用户拒绝，降级
  },
});
```

### 4.2 手机号

- 使用 `button open-type="getPhoneNumber"`，后端用 code 换手机号。
- 不要试图在前端解密/伪造。

### 4.3 授权原则

- 最小必要。
- 用到时再请求，不要一启动全要。
- 拒绝后给降级方案。
- 隐私政策真实/可读。

## 5. Skyline 渲染引擎

Skyline 是微信的新渲染引擎，目标：

- 更好的性能/交互。
- 支持 worklet 动画、手势。
- 更接近原生的滚动/渲染体验。

开启（页面级）：

```json
{
  "renderer": "skyline",
  "componentFramework": "glass-easel",
  "rendererOptions": {
    "skyline": {
      "defaultDisplayBlock": true
    }
  }
}
```

注意：

- 兼容性/基础库版本。
- 部分组件/样式行为与 WebView 不同。
- 适合长列表/复杂交互/动画；老页面不要盲目全量切。
- worklet 动画按官方文档使用。

## 6. 性能进阶

### 6.1 setData

- 只传变化字段/路径更新。
- 合并更新。
- 不要在滚动回调里 setData。
- 大列表分页/虚拟列表。
- 避免传大对象/函数。

### 6.2 分包异步化

- 分包异步化：跨分包引用 JS 时用 `require.async`。
- 独立分包：活动页/广告页，不依赖主包。
- `preloadRule` 预下载。
- `lazyCodeLoading: "requiredComponents"`。

### 6.3 首屏

- 骨架屏。
- 初始渲染缓存（按官方配置）。
- 图片 CDN/懒加载。
- 减少启动时的同步任务。
- 首屏数据接口合并/缓存。

### 6.4 长列表

- `recycle-view`/虚拟列表。
- 分页 + 触底加载。
- 列表项组件化、减少节点。
- 图片缩略图/懒加载。

### 6.5 其他

- 避免过深节点/复杂选择器。
- 减少 `wx:if` 频繁切换大块内容。
- 用 `hidden` 处理频繁显示/隐藏。
- 监控 setData 次数/耗时。

## 7. CI 自动化

`miniprogram-ci`：

```js
const ci = require('miniprogram-ci');

const project = new ci.Project({
  appid: 'wx1234567890',
  type: 'miniProgram',
  projectPath: process.cwd(),
  privateKeyPath: './private.key',
});

await ci.upload({
  project,
  version: '1.2.0',
  desc: 'feat: 商品列表',
  setting: {
    es6: true,
    minify: true,
  },
  onProgressUpdate: console.log,
});
```

- 私钥在公众平台生成，放 CI secrets。
- 可以接 GitHub Actions/Jenkins。
- 上传后到公众平台提审/发布。
- 自动化测试用 `miniprogram-automator`。

## 9. 面试高频

### Q1：云开发是什么？优缺点？ ⭐⭐

**答：** 微信提供的云数据库/存储/云函数/云调用，不用自建服务器；优点是集成快、适合中小项目；缺点是绑定微信生态、复杂查询/事务/迁移成本高。

### Q2：订阅消息怎么实现？ ⭐⭐

**答：** 申请模板拿 tmplId，用户点击按钮时 `wx.requestSubscribeMessage`，同意后后端记录，后续由后端调微信接口发送；必须在用户手势里调用，拒绝后不要反复弹。

### Q3：小程序码怎么生成/接收参数？ ⭐⭐

**答：** 服务端调 `wxacode.getUnlimited` 生成，scene 有长度限制；用户扫码进入 onLoad，`options.scene` 需要 decode。

### Q4：隐私授权怎么处理？ ⭐⭐

**答：** 配置隐私保护指引，用 `wx.requirePrivacyAuthorize` 在需要时请求；最小必要、拒绝给降级、隐私政策真实。

### Q5：Skyline 是什么？ ⭐⭐

**答：** 微信的新渲染引擎，提升性能/交互/动画，支持 worklet；要注意基础库/组件兼容，适合长列表/复杂交互，不要盲目全量切。

### Q6：小程序性能进阶怎么做？ ⭐⭐⭐

**答：** setData 路径更新/合并/防抖；分包异步化/预下载/按需注入；首屏骨架/缓存；长列表虚拟化；图片优化；Skyline（按需）。

### Q7：分包异步化是什么？ ⭐⭐

**答：** 跨分包引用 JS 时用 `require.async` 异步加载，避免主包/分包强依赖；配合预下载减少等待。

### Q8：小程序 CI 怎么做？ ⭐⭐

**答：** 用 miniprogram-ci，配置 appid/私钥/项目路径，在 CI 里 upload；私钥放 secrets；上传后提审/发布；自动化测试用 automator。

### Q9：小程序登录/手机号怎么拿？ ⭐⭐

**答：** 登录用 wx.login code 换 openid；手机号用 `button open-type="getPhoneNumber"` 拿 code，后端换手机号；secret/解密都在后端。

### Q10：小程序支付要注意什么？ ⭐⭐

**答：** 后端下单/签名，前端 requestPayment；金额/订单状态以后端为准；处理取消/失败/重复支付/掉单；回调验签。

### Q11：跨端框架怎么选？ ⭐⭐

**答：** 只做微信/依赖原生能力/性能敏感用原生；多端复用用 Taro/uni-app；接受平台差异/调试成本，不要承诺完全一致。

### Q12：小程序怎么做监控？ ⭐⭐

**答：** App.onError/onUnhandledRejection、接口失败、性能（启动/首屏/setData）、版本/机型/基础库维度；接自建/第三方平台，设告警。
