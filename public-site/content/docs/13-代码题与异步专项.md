# 13 · 代码题与异步专项

> 目标：给你一个需求，你能在 20-30 分钟内写出可运行、能处理边界、能讲清楚复杂度的代码。
>
> 适用：笔试、现场手写、白板编程、项目里的工具函数/请求封装/列表逻辑。
>
> 用法：
> 1. 先只看“需求/示例/验收”，自己写。
> 2. 写不出来再看参考实现。
> 3. 写完必须自己跑 3 组测试：正常、空、边界。

---

## 1. 现场写代码的 6 步

### 第 1 步：确认需求

不要急着写。先问清楚：

- 输入是什么？类型？范围？可能为空吗？
- 输出是什么？顺序有要求吗？
- 要不要处理错误/超时/取消？
- 并发有上限吗？
- 时间复杂度/空间复杂度有要求吗？

### 第 2 步：举例

```text
输入：[1, 2, 3]
输出：[2, 4, 6]

输入：[]
输出：[]

输入：null
输出：[] 或抛错？
```

### 第 3 步：说思路

先给暴力解，再说优化：

> 暴力解是双重循环 O(n²)。可以用哈希表把查找降到 O(1)，整体 O(n)，空间 O(n)。

### 第 4 步：写代码

- 函数名/变量名有意义。
- 先处理边界（空、null、类型不对）。
- 主逻辑短小。
- 不要过早优化。

### 第 5 步：手动跑

拿一组数据，逐步说出变量变化。

### 第 6 步：分析复杂度和边界

- 时间/空间。
- 空数组、单元素、重复元素、超大输入。
- 是否修改入参。

## 2. 异步专项（12 题）

### 2.1 实现 `sleep(ms)`

**需求：** 等待 `ms` 毫秒后继续。

```js
const sleep = (ms) =>
  new Promise((resolve) => setTimeout(resolve, ms));

// 使用
async function demo() {
  console.log('start');
  await sleep(1000);
  console.log('after 1s');
}
```

**边界：**

- `ms` 为 0：下一个宏任务。
- 负数：setTimeout 当作 0。
- 不要在 sleep 里阻塞主线程（JS 没有 sleep 同步原语）。

### 2.2 实现 `fetchWithTimeout(url, options, timeout)`

**需求：** 请求超过 `timeout` 毫秒就中止，并抛出“超时”。

```js
async function fetchWithTimeout(url, options = {}, timeout = 5000) {
  const controller = new AbortController();
  const timer = setTimeout(() => controller.abort(), timeout);

  // 兼容调用方自己传入的 signal
  const externalSignal = options.signal;
  const onExternalAbort = () => controller.abort();

  if (externalSignal) {
    externalSignal.addEventListener('abort', onExternalAbort, { once: true });
  }

  try {
    return await fetch(url, {
      ...options,
      signal: controller.signal,
    });
  } catch (err) {
    if (err.name === 'AbortError') {
      throw new Error('请求超时或已取消');
    }
    throw err;
  } finally {
    clearTimeout(timer);
    if (externalSignal) {
      externalSignal.removeEventListener('abort', onExternalAbort);
    }
  }
}
```

**测试：**

```js
// 正常
const res = await fetchWithTimeout('/api/data', {}, 3000);

// 超时
await fetchWithTimeout('/api/slow', {}, 100);
// Error: 请求超时或已取消
```

**延伸：**

- 现代浏览器可以用 `AbortSignal.timeout(ms)`、`AbortSignal.any([...])`。
- 中止请求后，服务端可能仍在处理；重要操作要做幂等。

### 2.3 实现 `retry(fn, options)`

**需求：** 失败后重试，支持次数、延迟、指数退避、随机抖动。

```js
const sleep = (ms) => new Promise((r) => setTimeout(r, ms));

async function retry(fn, options = {}) {
  const {
    times = 3,
    delay = 500,
    backoff = 2,
    jitter = true,
  } = options;

  let lastError;

  for (let attempt = 1; attempt <= times; attempt++) {
    try {
      return await fn(attempt);
    } catch (err) {
      lastError = err;
      if (attempt === times) break;

      const base = delay * Math.pow(backoff, attempt - 1);
      const wait = jitter
        ? base * (0.5 + Math.random() * 0.5)
        : base;

      await sleep(wait);
    }
  }

  throw lastError;
}
```

**测试：**

```js
let count = 0;

const result = await retry(
  async () => {
    count++;
    if (count < 3) throw new Error('暂时失败');
    return 'ok';
  },
  { times: 3, delay: 10 }
);

console.log(result); // ok
console.log(count);  // 3
```

**注意：**

- 只重试**幂等**操作（GET、查询），不要随便重试支付/下单。
- 区分可重试错误（网络、5xx）和不可重试错误（400、401）。
- 重试要有上限和总超时，避免雪崩。

### 2.4 实现 `runWithLimit(tasks, limit)`

**需求：** 最多同时执行 `limit` 个任务，返回结果数组（顺序与任务顺序一致）。

```js
async function runWithLimit(tasks, limit = 3) {
  const results = new Array(tasks.length);
  let nextIndex = 0;

  async function worker() {
    while (nextIndex < tasks.length) {
      const index = nextIndex++;
      results[index] = await tasks[index]();
    }
  }

  const workerCount = Math.min(limit, tasks.length);
  const workers = Array.from({ length: workerCount }, () => worker());

  await Promise.all(workers);
  return results;
}
```

**测试：**

```js
const tasks = [1, 2, 3, 4, 5].map((n) => async () => {
  await sleep(100);
  return n * 2;
});

const results = await runWithLimit(tasks, 2);
console.log(results); // [2, 4, 6, 8, 10]
```

**边界：**

- `tasks` 为空：返回 `[]`。
- `limit <= 0`：抛错或改成 1。
- 某个任务失败：当前实现会让 `Promise.all` reject，其他 worker 可能还在跑。需要全部结束用 `Promise.allSettled(workers)`，再把错误抛出。

**进阶：** 用 `p-limit` 或自己实现一个限流器（见 2.11）。

### 2.5 串行 vs 并行

**需求：** 实现 `runSequential(tasks)` 和 `runParallel(tasks)`。

```js
async function runSequential(tasks) {
  const results = [];
  for (const task of tasks) {
    results.push(await task());
  }
  return results;
}

async function runParallel(tasks) {
  return Promise.all(tasks.map((task) => task()));
}
```

**什么时候用：**

| 场景 | 选择 |
|---|---|
| 后一个请求依赖前一个结果 | 串行 |
| 多个接口互不依赖 | 并行 |
| 接口很多，怕压垮服务 | 限流并发 |
| 需要按顺序展示，但可同时请求 | 并行 + 结果数组保持顺序 |

**注意：** `Promise.all` 的顺序和传入顺序一致，不是完成顺序。

### 2.6 只保留最新请求（搜索竞态）

**需求：** 快速输入时，只渲染最后一次请求的结果。

```js
function createLatestRequest() {
  let controller = null;

  return async function run(requestFn) {
    if (controller) controller.abort();
    controller = new AbortController();

    try {
      return await requestFn(controller.signal);
    } catch (err) {
      if (err.name === 'AbortError') return null; // 被取消，不算错误
      throw err;
    }
  };
}
```

**使用：**

```js
const latest = createLatestRequest();

input.addEventListener('input', async (e) => {
  const data = await latest((signal) =>
    fetch(`/api/search?q=${encodeURIComponent(e.target.value)}`, { signal })
      .then((res) => res.json())
  );

  if (data) render(data);
});
```

**边界：**

- 旧请求被取消时返回 null，调用方要判断。
- 如果不想取消，只丢弃结果，可以用请求序号：

```js
let requestId = 0;

async function search(keyword) {
  const current = ++requestId;
  const data = await fetchData(keyword);
  if (current !== requestId) return;
  render(data);
}
```

### 2.7 异步缓存：相同参数只请求一次

**需求：** 同一个 key 的并发请求只发一次；失败不缓存。

```js
function asyncMemoize(fn) {
  const cache = new Map(); // key -> Promise

  function memoized(...args) {
    const key = JSON.stringify(args);

    if (cache.has(key)) {
      return cache.get(key);
    }

    const promise = Promise.resolve()
      .then(() => fn.apply(this, args))
      .catch((err) => {
        cache.delete(key); // 失败不缓存，允许重试
        throw err;
      });

    cache.set(key, promise);
    return promise;
  }

  memoized.clear = () => cache.clear();
  return memoized;
}
```

**测试：**

```js
let calls = 0;

const getUser = asyncMemoize(async (id) => {
  calls++;
  return { id };
});

await Promise.all([getUser(1), getUser(1), getUser(1)]);
console.log(calls); // 1
```

**注意：**

- `JSON.stringify` 作为 key 有局限：参数顺序、函数、undefined、循环引用。
- 需要过期时间，用带 TTL 的缓存。
- 内存缓存只适合小数据；大数据用 LRU。

### 2.8 给 Promise 加超时

**需求：** 超过 `ms` 就 reject，但原 Promise 无法真正取消。

```js
function withTimeout(promise, ms, message = '操作超时') {
  let timer;

  const timeout = new Promise((_, reject) => {
    timer = setTimeout(() => reject(new Error(message)), ms);
  });

  return Promise.race([promise, timeout]).finally(() => {
    clearTimeout(timer);
  });
}
```

**测试：**

```js
await withTimeout(sleep(1000), 100);
// Error: 操作超时
```

**注意：** `Promise.race` 只是让外层不再等，原 Promise 仍在执行。要真正取消，需要 `AbortController`。

### 2.9 手写 `Promise.all`

```js
function promiseAll(iterable) {
  return new Promise((resolve, reject) => {
    let items;

    try {
      items = Array.from(iterable);
    } catch (err) {
      return reject(err);
    }

    const results = new Array(items.length);
    let settled = 0;

    if (items.length === 0) return resolve(results);

    items.forEach((item, index) => {
      Promise.resolve(item).then(
        (value) => {
          results[index] = value;
          settled++;
          if (settled === items.length) resolve(results);
        },
        reject
      );
    });
  });
}
```

**测试：**

```js
await promiseAll([1, Promise.resolve(2), 3]); // [1, 2, 3]
await promiseAll([]);                        // []
```

### 2.10 异步队列 `AsyncQueue`

**需求：** 任务可以不断添加，最多同时执行 `limit` 个。

```js
class AsyncQueue {
  constructor(limit = 3) {
    this.limit = limit;
    this.running = 0;
    this.queue = [];
  }

  add(task) {
    return new Promise((resolve, reject) => {
      this.queue.push({ task, resolve, reject });
      this._next();
    });
  }

  _next() {
    while (this.running < this.limit && this.queue.length > 0) {
      const { task, resolve, reject } = this.queue.shift();

      this.running++;

      Promise.resolve()
        .then(task)
        .then(resolve, reject)
        .finally(() => {
          this.running--;
          this._next();
        });
    }
  }
}
```

**测试：**

```js
const queue = new AsyncQueue(2);

const results = await Promise.all([
  queue.add(async () => 1),
  queue.add(async () => 2),
  queue.add(async () => 3),
]);

console.log(results); // [1, 2, 3]
```

**用途：** 图片上传、批量请求、任务调度。

### 2.11 实现 `pLimit(limit)`

**需求：** 返回一个函数，调用它添加任务，自动限流。

```js
function pLimit(limit) {
  if (limit < 1) throw new Error('limit 必须 >= 1');

  const queue = [];
  let active = 0;

  function next() {
    if (active >= limit || queue.length === 0) return;

    active++;
    const { fn, resolve, reject } = queue.shift();

    Promise.resolve()
      .then(fn)
      .then(resolve, reject)
      .finally(() => {
        active--;
        next();
      });
  }

  return function limit(fn) {
    return new Promise((resolve, reject) => {
      queue.push({ fn, resolve, reject });
      next();
    });
  };
}
```

**使用：**

```js
const limit = pLimit(2);

const results = await Promise.all(
  [1, 2, 3, 4].map((n) => limit(async () => {
    await sleep(100);
    return n;
  }))
);

console.log(results); // [1, 2, 3, 4]
```

## 3. 数据处理专项（10 题）

### 3.1 深拷贝

```js
function deepClone(value, cache = new WeakMap()) {
  if (value === null || typeof value !== 'object') return value;
  if (cache.has(value)) return cache.get(value);

  if (value instanceof Date) return new Date(value);
  if (value instanceof RegExp) return new RegExp(value.source, value.flags);

  if (value instanceof Map) {
    const map = new Map();
    cache.set(value, map);
    value.forEach((v, k) => {
      map.set(deepClone(k, cache), deepClone(v, cache));
    });
    return map;
  }

  if (value instanceof Set) {
    const set = new Set();
    cache.set(value, set);
    value.forEach((v) => set.add(deepClone(v, cache)));
    return set;
  }

  const cloned = Array.isArray(value)
    ? []
    : Object.create(Object.getPrototypeOf(value));

  cache.set(value, cloned);

  for (const key of Reflect.ownKeys(value)) {
    cloned[key] = deepClone(value[key], cache);
  }

  return cloned;
}
```

**边界：** 循环引用、Date、RegExp、Map、Set、Symbol 键；函数按引用返回。

function flatten(arr, depth = Infinity) {

function groupBy(list, getKey) {

### 3.5 柯里化

```js
function curry(fn) {
  function curried(...args) {
    if (args.length >= fn.length) {
      return fn.apply(this, args);
    }
    return function (...nextArgs) {
      return curried.apply(this, [...args, ...nextArgs]);
    };
  }
  return curried;
}
```

**测试：**

```js

```

### 3.6 发布订阅 `EventEmitter`

```js
class EventEmitter {
  constructor() {
    this.events = new Map();
  }

  on(type, fn) {
    if (!this.events.has(type)) this.events.set(type, []);
    this.events.get(type).push(fn);

    return () => this.off(type, fn);
  }

  off(type, fn) {
    const list = this.events.get(type);
    if (!list) return;
    const index = list.indexOf(fn);
    if (index > -1) list.splice(index, 1);
    if (list.length === 0) this.events.delete(type);
  }

  once(type, fn) {
    const wrapper = (...args) => {
      this.off(type, wrapper);
      fn(...args);
    };
    this.on(type, wrapper);
  }

  emit(type, ...args) {
    const list = this.events.get(type);
    if (!list || list.length === 0) return false;

    [...list].forEach((fn) => fn(...args));
    return true;
  }
}
```

**测试：**

```js
const bus = new EventEmitter();
const off = bus.on('add', (n) => console.log('add', n));
bus.emit('add', 1);
off();
bus.emit('add', 2); // 不再触发
```

### 3.7 LRU 缓存

```js
class LRUCache {
  constructor(capacity) {
    this.capacity = capacity;
    this.map = new Map();
  }

  get(key) {
    if (!this.map.has(key)) return -1;

    const value = this.map.get(key);
    this.map.delete(key);
    this.map.set(key, value); // 移到末尾 = 最近使用
    return value;
  }

  put(key, value) {
    if (this.map.has(key)) this.map.delete(key);
    this.map.set(key, value);

    if (this.map.size > this.capacity) {
      const oldest = this.map.keys().next().value;
      this.map.delete(oldest);
    }
  }
}
```

**复杂度：** `Map` 的增删查平均 O(1)。

### 3.8 带 TTL 的缓存

```js
function memoizeWithTTL(fn, ttl = 5000) {
  const cache = new Map();

  function memoized(...args) {
    const key = JSON.stringify(args);
    const now = Date.now();
    const hit = cache.get(key);

    if (hit && now - hit.time < ttl) {
      return hit.value;
    }

    const value = fn.apply(this, args);
    cache.set(key, { value, time: now });
    return value;
  }

  memoized.clear = () => cache.clear();
  return memoized;
}
```

**注意：** 过期数据不会主动清理，适合小缓存；大缓存要定期清理或使用 LRU。

function formatMoney(cents, symbol = '¥') {

## 4. 前端 / RN / 小程序专项（8 题）

### 4.1 带取消的防抖

```js
function debounce(fn, delay = 300) {
  let timer = null;

  function debounced(...args) {
    if (timer) clearTimeout(timer);

    timer = setTimeout(() => {
      timer = null;
      fn.apply(this, args);
    }, delay);
  }

  debounced.cancel = () => {
    if (timer) clearTimeout(timer);
    timer = null;
  };

  return debounced;
}
```

**使用：**

```js
const onSearch = debounce((keyword) => search(keyword), 300);
input.addEventListener('input', (e) => onSearch(e.target.value));

// 页面卸载
onSearch.cancel();
```

### 4.2 支持 leading/trailing 的节流

```js
function throttle(fn, interval = 300, options = {}) {
  const { leading = true, trailing = true } = options;

  let last = 0;
  let timer = null;
  let lastArgs = null;
  let lastThis = null;

  function invoke(time) {
    last = time;
    timer = null;
    if (lastArgs) {
      fn.apply(lastThis, lastArgs);
      lastArgs = null;
      lastThis = null;
    }
  }

  function throttled(...args) {
    const now = Date.now();

    if (last === 0 && !leading) {
      last = now;
    }

    const remaining = interval - (now - last);
    lastArgs = args;
    lastThis = this;

    if (remaining <= 0) {
      if (timer) {
        clearTimeout(timer);
        timer = null;
      }
      invoke(now);
    } else if (!timer && trailing) {
      timer = setTimeout(() => invoke(Date.now()), remaining);
    }
  }

  throttled.cancel = () => {
    if (timer) clearTimeout(timer);
    timer = null;
    last = 0;
    lastArgs = null;
    lastThis = null;
  };

  return throttled;
}
```

### 4.3 React `useDebouncedValue`

```jsx
import { useEffect, useState } from 'react';

function useDebouncedValue(value, delay = 300) {
  const [debounced, setDebounced] = useState(value);

  useEffect(() => {
    const timer = setTimeout(() => setDebounced(value), delay);
    return () => clearTimeout(timer);
  }, [value, delay]);

  return debounced;
}
```

  }, [debouncedKeyword]);

### 4.4 React `useFetch`

**需求：** 请求 URL，返回 `data/loading/error`，URL 变化时取消旧请求。

```jsx
import { useEffect, useState } from 'react';

function useFetch(url) {
  const [state, setState] = useState({
    data: null,
    loading: Boolean(url),
    error: null,
  });

  useEffect(() => {
    if (!url) {
      setState({ data: null, loading: false, error: null });
      return;
    }

    const controller = new AbortController();
    let active = true;

    setState((prev) => ({ ...prev, loading: true, error: null }));

    fetch(url, { signal: controller.signal })
      .then((res) => {
        if (!res.ok) throw new Error(`HTTP ${res.status}`);
        return res.json();
      })
      .then((data) => {
        if (active) {
          setState({ data, loading: false, error: null });
        }
      })
      .catch((err) => {
        if (err.name === 'AbortError') return;
        if (active) {
          setState({ data: null, loading: false, error: err });
        }
      });

    return () => {
      active = false;
      controller.abort();
    };
  }, [url]);

  return state;
}
```

**使用：**

```jsx
function ProductPage({ keyword }) {
  const url = keyword
    ? `https://dummyjson.com/products/search?q=${encodeURIComponent(keyword)}`
    : 'https://dummyjson.com/products?limit=20';

  const { data, loading, error } = useFetch(url);

  if (loading) return <p>加载中...</p>;
  if (error) return <p>加载失败：{error.message}</p>;

  const list = data?.products ?? [];
  if (list.length === 0) return <p>暂无数据</p>;

  return (
    <ul>
      {list.map((item) => (
        <li key={item.id}>{item.title}</li>
      ))}
    </ul>
  );
}
```

### 4.6 RN 分页 Hook

**需求：** 首屏加载、下拉刷新、上拉加载更多、防止重复请求。

```jsx
import { useCallback, useEffect, useRef, useState } from 'react';

const PAGE_SIZE = 10;

function usePaginatedPosts() {
  const [items, setItems] = useState([]);
  const [refreshing, setRefreshing] = useState(false);
  const [loadingMore, setLoadingMore] = useState(false);
  const [hasMore, setHasMore] = useState(true);
  const [error, setError] = useState(null);

  const pageRef = useRef(1);
  const loadingRef = useRef(false);

  const load = useCallback(async (page, replace = false) => {
    if (loadingRef.current) return;
    loadingRef.current = true;

    if (replace) setRefreshing(true);
    else setLoadingMore(true);

    setError(null);

    try {
      const res = await fetch(
        `https://jsonplaceholder.typicode.com/posts?_page=${page}&_limit=${PAGE_SIZE}`
      );
      if (!res.ok) throw new Error(`HTTP ${res.status}`);

      const data = await res.json();

      setItems((prev) => (replace ? data : [...prev, ...data]));
      setHasMore(data.length === PAGE_SIZE);
      pageRef.current = page;
    } catch (err) {
      setError(err);
    } finally {
      loadingRef.current = false;
      setRefreshing(false);
      setLoadingMore(false);
    }
  }, []);

  useEffect(() => {
    load(1, true);
  }, [load]);

  const refresh = useCallback(() => load(1, true), [load]);

  const loadMore = useCallback(() => {
    if (!hasMore || loadingRef.current) return;
    load(pageRef.current + 1);
  }, [hasMore, load]);

  return {
    items,
    refreshing,
    loadingMore,
    hasMore,
    error,
    refresh,
    loadMore,
  };
}
```

**FlatList 使用：**

```jsx
const { items, refreshing, loadingMore, error, refresh, loadMore } =
  usePaginatedPosts();

<FlatList
  data={items}
  keyExtractor={(item) => String(item.id)}
  renderItem={({ item }) => <PostCard post={item} />}
  refreshing={refreshing}
  onRefresh={refresh}
  onEndReached={loadMore}
  onEndReachedThreshold={0.3}
  ListFooterComponent={
    loadingMore ? <ActivityIndicator /> : error ? <Text>{error.message}</Text> : null
  }
/>
```

### 4.7 小程序请求封装

```js
// utils/request.js
const BASE_URL = 'https://api.example.com';

function request({ url, method = 'GET', data = {}, header = {} }) {
  const token = wx.getStorageSync('token');

  return new Promise((resolve, reject) => {
    wx.request({
      url: BASE_URL + url,
      method,
      data,
      header: {
        'Content-Type': 'application/json',
        ...(token ? { Authorization: `Bearer ${token}` } : {}),
        ...header,
      },
      timeout: 10000,

      success(res) {
        if (res.statusCode === 401) {
          wx.removeStorageSync('token');
          reject(new Error('登录已过期'));
          return;
        }

        if (res.statusCode >= 200 && res.statusCode < 300) {
          resolve(res.data);
        } else {
          reject(new Error(`HTTP ${res.statusCode}`));
        }
      },

      fail(err) {
        reject(new Error(err.errMsg || '网络错误'));
      },
    });
  });
}

module.exports = { request };
```

**注意：** 域名要在公众平台配置；开发工具可临时关闭校验。

### 4.8 小程序 `setData` 路径更新

**需求：** 只更新列表中某一项的某个字段，不传整个列表。

```js
Page({
  data: {
    list: [
      { id: 1, title: 'A', done: false },
      { id: 2, title: 'B', done: false },
    ],
  },

  toggle(index) {
    const key = `list[${index}].done`;

    this.setData({
      [key]: !this.data.list[index].done,
    });
  },
});
```

**为什么：**

- 只传变化的字段，减少序列化和通信。
- 不要 `this.data.list.push(...)` 后直接 setData 整个列表。

## 5. 25 道限时练习题（只给需求与验收）

> 每题限时 20 分钟。先自己写，再对照前面的实现或 03/08 文档。

### 异步

1. **`mapLimit(list, fn, limit)`**：对数组每个元素执行异步 fn，最多并发 limit，结果保持顺序。
2. **`promiseAny`**：第一个成功就 resolve，全部失败 reject 一个 AggregateError。
3. **可取消的 Promise**：返回 `{ promise, cancel }`，cancel 后 reject AbortError。
4. **异步缓存 + TTL**：相同参数 5 秒内只请求一次。
5. **批量请求合并**：10ms 内的多个请求合并成一次批量接口。
6. **异步 reduce**：用 reduce 串行执行异步任务。
7. **失败降级**：主接口失败时请求备用接口，都失败返回默认值。
8. **重试 + 总超时**：最多重试 3 次，但总时间不超过 5 秒。

### 数据处理

9. **`deepEqual(a, b)`**：支持对象、数组、Date、NaN。
10. **`chunk(arr, size)`**：按固定大小分组。
11. **树转列表 / 列表转树**：`id/parentId` 结构。
12. **`diffArray(oldList, newList, key)`**：返回 added/removed/updated。
13. **多字段排序**：先按 status，再按 createdAt 倒序。
14. **`get(obj, 'a.b[0].c', default)`**：安全读取深层属性。
15. **`set(obj, path, value)`**：不可变地设置深层属性。

### 前端

16. **虚拟列表**：只渲染可视区域的 1000 条数据。
17. **无限滚动**：滚动到底部加载下一页，防止重复请求。
18. **请求封装 + 401 刷新队列**：token 过期时只刷新一次，其他请求排队等待。
19. **大文件分片上传**：切片、并发、进度、失败重试。
20. **搜索历史**：最多 10 条、去重、最近在前、本地存储。
21. **表格分页 + 搜索 + 排序**：状态同步到 URL。
22. **主题切换**：CSS 变量 + 本地存储 + 首屏不闪。
23. **图片懒加载**：IntersectionObserver。

### RN / 小程序

24. **RN FlatList 固定行高优化**：`getItemLayout` + `memo` + 分页。
25. **小程序登录流程**：`wx.login` → 后端换 token → 存储 → 请求带 token → 401 重登。
