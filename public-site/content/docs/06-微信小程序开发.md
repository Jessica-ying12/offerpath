# 06 · 微信小程序开发

> 目标：能独立开发小程序页面、组件、路由、请求、分包，并理解双线程和 setData 的性能问题。
>
> 标记：⭐⭐⭐ 必须会｜⭐⭐ 要理解｜⭐ 了解即可

## 1. 小程序是什么

微信小程序是运行在微信里的应用，用 WXML、WXSS、JS 开发，由微信客户端提供运行环境和原生能力。

- 不需要下载安装，扫码/搜索即用。
- 有审核和发布流程。
- 包体积有限制（主包约 2MB，总包约 30MB，具体以官方最新文档为准）。
- 能调用微信能力：登录、支付、定位、扫码、相机、分享等。

### 1.1 和 H5 的区别

| 维度 | H5 | 小程序 |
|---|---|---|
| 运行环境 | 浏览器/WebView | 微信客户端 |
| 标签 | HTML | WXML |
| 样式 | CSS | WXSS（rpx） |
| 路由 | URL | wx.navigateTo 等 |
| 请求 | fetch/XHR | wx.request（需配置域名） |
| 登录 | 自定义 | wx.login + 后端换 openid |
| 支付 | 对接支付网关 | wx.requestPayment |
| 发布 | 部署即上线 | 审核发布 |
| 包体 | 无硬限制 | 主包/总包限制 |
| 性能 | 受 WebView 限制 | 双线程 + 原生能力 |

### 1.2 和 React 的区别

| React | 小程序 |
|---|---|
| JSX | WXML |
| CSS/className | WXSS/class |
| useState/setState | `this.setData` |
| props | properties |
| 组件函数 | `Component({})` |
| react-router | wx.navigateTo |
| useEffect | onLoad/onShow/observers |
| 虚拟 DOM | 逻辑层/视图层通信 |

## 2. 开发准备

1. 注册小程序账号，拿到 AppID（学习可用测试号）。
2. 下载微信开发者工具。
3. 新建项目，选择目录、AppID、模板（JavaScript - 基础）。
4. 目录结构：

```text

├── app.wxss            # 全局样式
├── project.config.json # 项目配置

├── pages/
│   ├── index/

│   │   ├── index.json
```

```json
{
  "pages": [

  ],
  "window": {
    "navigationBarTitleText": "商城",
    "navigationBarBackgroundColor": "#ffffff",

    "list": [

  },
```

| 字段 | 作用 |
|---|---|

| `sitemapLocation` | 搜索索引配置 |

> `tabBar` 的页面必须用 `wx.switchTab` 跳转，不能用 `wx.navigateTo`。

## 4. 逻辑层：`App` 与 `Page` ⭐⭐⭐

### 4.1 `app.js`

```js
App({
  // 全局数据，所有页面可以通过 getApp() 访问
  globalData: {
    userInfo: null,
    token: '',
  },

  // 小程序启动时执行一次
  onLaunch(options) {
    console.log('启动参数', options);

    // 读取本地 token
    const token = wx.getStorageSync('token');
    if (token) {
      this.globalData.token = token;
    }
  },

  // 从后台切回前台
  onShow(options) {
    console.log('显示', options);
  },

  // 切到后台
  onHide() {
    console.log('隐藏');
  },

  // 全局错误
  onError(err) {
    console.error('全局错误', err);
  },
});
```

页面里获取：

```js
const app = getApp();
console.log(app.globalData.token);
```

### 4.2 `Page` 生命周期 ⭐⭐⭐

```js
Page({
  data: {
    list: [],
    loading: true,
  },

  // 1. 页面加载，只执行一次；可以接收路由参数
  onLoad(options) {
    console.log('onLoad', options.id);
    this.loadList();
  },

  // 2. 页面显示，每次进入前台都执行（包括从详情返回）
  onShow() {
    console.log('onShow');
  },

  // 3. 页面首次渲染完成，只执行一次
  onReady() {
    console.log('onReady');
  },

  // 4. 页面隐藏（切后台、跳走）
  onHide() {
    console.log('onHide');
  },

  // 5. 页面卸载（navigateBack/reLaunch）
  onUnload() {
    console.log('onUnload');
    if (this.timer) clearTimeout(this.timer);
  },

  // 下拉刷新
  onPullDownRefresh() {
    this.loadList().finally(() => wx.stopPullDownRefresh());
  },

  // 上拉触底
  onReachBottom() {
    console.log('加载更多');
  },

  // 页面滚动
  onPageScroll(e) {
    // 高频触发，不要在这里 setData
  },

  // 分享
  onShareAppMessage() {
    return {
      title: '推荐一个商城',
      path: '/pages/index/index',
    };
  },
});
```

**`onLoad` vs `onShow`：**

- `onLoad` 只执行一次，适合初始化、请求首屏数据、接收参数。
- `onShow` 每次显示都执行，适合刷新用户状态、从后台回来更新数据。

## 5. WXML ⭐⭐⭐

### 5.1 数据绑定

```xml
<view class="card">
  <text>{{title}}</text>
  <text>{{price}} 元</text>
  <text>{{user.name}}</text>
  <text>{{isVip ? '会员' : '普通'}}</text>
  <text>{{count + 1}}</text>
  <image src="{{cover}}" mode="aspectFill" />
</view>
```

`{{}}` 里只能写**简单表达式**，不能写函数调用、语句：

```xml
<!-- 不行：WXML 不支持调用方法 -->
<text>{{formatPrice(price)}}</text>

<!-- 解决 1：在 JS 里先算好 -->
<text>{{priceText}}</text>

<!-- 解决 2：用 WXS -->
<wxs module="fmt">
  module.exports = {
    price: function (n) {
      return '¥' + n.toFixed(2);
    }
  }
</wxs>
<text>{{fmt.price(price)}}</text>
```

### 5.2 条件渲染

```xml
<view wx:if="{{loading}}">加载中...</view>
<view wx:elif="{{error}}">{{error}}</view>
<view wx:elif="{{list.length === 0}}">暂无数据</view>
<view wx:else>
  <view wx:for="{{list}}" wx:key="id">{{item.title}}</view>
</view>
```

`wx:if` vs `hidden`：

| 方式 | 行为 | 场景 |
|---|---|---|
| `wx:if` | 条件为假时销毁节点 | 不常切换、初始可能不渲染 |
| `hidden` | 始终渲染，只是隐藏 | 频繁切换、需要保留状态 |

### 5.3 列表渲染

```xml
<!-- 默认 item 是当前项，index 是索引 -->
<view wx:for="{{list}}" wx:key="id">
  {{index}} - {{item.title}}
</view>

<!-- 自定义变量名 -->
<view wx:for="{{list}}" wx:for-item="goods" wx:for-index="i" wx:key="id">
  {{i}} - {{goods.title}}
</view>

<!-- 嵌套循环：内层变量名必须改，否则会覆盖外层 -->
<view wx:for="{{groups}}" wx:for-item="group" wx:key="id">
  <view wx:for="{{group.items}}" wx:for-item="goods" wx:key="id">
    {{goods.title}}
  </view>
</view>
```

`wx:key` 的值：

- 字符串：数组项对象的某个唯一属性名，例如 `id`。
- `*this`：数组项本身是唯一字符串/数字时使用。

**不要用 index 做 key**，列表变化时会错乱。

### 5.4 `block`

`block` 不是组件，不会渲染成 DOM，只用来包裹一组节点：

```xml
<block wx:if="{{isLogin}}">
  <view>欢迎</view>
  <view>个人中心</view>
</block>
```

### 5.5 模板与引用

```xml
<!-- 定义模板 -->
<template name="goods">
  <view class="goods">
    <text>{{title}}</text>
    <text>{{price}}</text>
  </view>
</template>

<!-- 使用模板 -->
<template is="goods" data="{{...item}}" />
```

```xml
<!-- import：引入模板定义 -->
<import src="./goods-template.wxml" />

<!-- include：引入整个文件内容（除了 template/wxs） -->
<include src="./header.wxml" />
```

### 5.6 事件绑定

```xml
<!-- bindtap：冒泡 -->
<view bindtap="onTap" data-id="{{item.id}}">点击</view>

<!-- catchtap：阻止冒泡 -->
<view catchtap="onInner">内部</view>

<!-- 表单事件 -->
<input bindinput="onInput" bindconfirm="onConfirm" />
<form bindsubmit="onSubmit">
  <button form-type="submit">提交</button>
</form>
```

```js
Page({
  onTap(e) {
    // currentTarget 是绑定事件的元素；target 是实际触发的元素
    const id = e.currentTarget.dataset.id;
    console.log(id);
  },

  onInput(e) {
    console.log(e.detail.value);
  },
});
```

事件名可以带冒号和连字符：

```xml
<view bind:tap="onTap" />
<view bindtouchstart="onTouchStart" />
```

## 6. WXSS ⭐⭐

### 6.1 rpx

`rpx` 是小程序的响应式单位：

```text
750rpx = 屏幕宽度
1rpx = 屏幕宽度 / 750
```

设计稿宽度通常是 750px，所以设计稿上多少 px，就写多少 rpx：

```css
/* 设计稿 32px 字号 */
.title { font-size: 32rpx; }

/* 设计稿 24px 间距 */
.card { padding: 24rpx; }
```

### 6.2 样式文件

```css
/* app.wxss：全局样式 */
page {
  background: #f5f5f5;
  font-family: -apple-system, "PingFang SC", sans-serif;
}

/* 页面 wxss：只作用于当前页面 */
.container { padding: 24rpx; }

/* 引入其他样式 */
@import "./common.wxss";
```

### 6.3 选择器

支持类、id、元素、伪类、伪元素等，但：

- 推荐用 **class 选择器**。
- 少用标签选择器、ID 选择器、后代选择器（性能和无障碍考虑）。
- 自定义组件默认样式隔离，外部类名不影响内部。

### 6.4 组件样式隔离

```js
Component({
  options: {
    styleIsolation: 'isolated', // 默认：内外互不影响
    // 'apply-shared'：外部样式影响组件内部
    // 'shared'：双向影响
  },
});
```

## 8. 路由与传参 ⭐⭐⭐

| API | 行为 | 场景 |
|---|---|---|
| `wx.navigateTo` | 保留当前页，压栈 | 列表 → 详情（最多 10 层） |
| `wx.redirectTo` | 关闭当前页，替换 | 登录成功 → 首页 |
| `wx.switchTab` | 切换到 tabBar 页 | 底部导航 |
| `wx.reLaunch` | 关闭所有页面，打开指定页 | 退出登录、重置 |
| `wx.navigateBack` | 返回上一页/多页 | 详情 → 列表 |

```js
// 跳转并传参
wx.navigateTo({
  url: `/pages/detail/detail?id=${id}&from=list`,
});

// 详情页接收
Page({
  onLoad(options) {
    console.log(options.id, options.from); // 字符串
  },
});

// 返回
wx.navigateBack({ delta: 1 });

// 重定向
wx.redirectTo({ url: '/pages/login/login' });

// 切换 tab
wx.switchTab({ url: '/pages/index/index' });

// 重启
wx.reLaunch({ url: '/pages/index/index' });
```

**注意：**

- 参数会拼在 URL 上，注意 `encodeURIComponent`。
- `navigateTo` 不能跳到 tabBar 页面。
- 复杂数据不要用 URL 传，可以用全局变量、缓存或 `EventChannel`。

```js
// EventChannel：页面间通信
wx.navigateTo({
  url: '/pages/detail/detail',
  success(res) {
    res.eventChannel.emit('acceptData', { id: 1 });
  },
});

// 详情页
Page({
  onLoad() {
    const eventChannel = this.getOpenerEventChannel();
    eventChannel.on('acceptData', (data) => {
      console.log(data);
    });
  },
});
```

## 9. 网络请求 ⭐⭐⭐

### 9.1 `wx.request`

```js
wx.request({
  url: 'https://api.example.com/goods',
  method: 'GET',
  data: { page: 1, keyword: '耳机' },
  header: {
    'Content-Type': 'application/json',
    Authorization: `Bearer ${token}`,
  },
  timeout: 10000,
  success(res) {
    if (res.statusCode >= 200 && res.statusCode < 300) {
      console.log(res.data);
    } else {
      console.error('HTTP', res.statusCode);
    }
  },
  fail(err) {
    console.error('网络错误', err);
  },
  complete() {
    console.log('请求结束');
  },
});
```

### 9.2 域名配置

- 小程序只能请求**已配置的合法域名**，必须是 HTTPS。
- 在微信公众平台 → 开发 → 开发设置 → 服务器域名里配置。
- 开发者工具可以勾选“不校验合法域名”临时调试，但真机/上线必须配置。
- 本地开发可以用内网穿透/代理，但上线要用正式域名。

### 9.3 Promise 封装

```js
// utils/request.js
const BASE_URL = 'https://api.example.com';

function request({ url, method = 'GET', data = {}, header = {} }) {
  return new Promise((resolve, reject) => {
    wx.request({
      url: BASE_URL + url,
      method,
      data,
      header: {
        'Content-Type': 'application/json',
        ...header,
      },
      timeout: 10000,

      success(res) {
        if (res.statusCode >= 200 && res.statusCode < 300) {
          resolve(res.data);
        } else {
          reject(new Error(`HTTP ${res.statusCode}`));
        }
      },

      fail(err) {
        reject(new Error(err.errMsg || '网络错误'));
      },
    });
  });
}

module.exports = { request };
```

```js
const { request } = require('../../utils/request');

async function loadGoods(keyword) {
  return request({
    url: '/goods',
    data: { keyword },
  });
}
```

### 9.4 登录流程 ⭐⭐⭐

```text
小程序                          后端                        微信服务器
  |                              |                              |
  |-- wx.login() --------------->|                              |
  |<-- code ---------------------|                              |
  |-- 把 code 发给后端 ---------------------------------------->|
  |                              |-- code2session(appid, secret, code) -->|
  |                              |<-- openid, session_key ------|
  |                              |-- 生成自定义 token ----------|
  |<-- token --------------------|                              |
  |-- 后续请求带 token ---------------------------------------->|
```

```js
// 小程序端
wx.login({
  success(res) {
    if (!res.code) return;

    wx.request({
      url: 'https://api.example.com/auth/login',
      method: 'POST',
      data: { code: res.code },
      success(response) {
        const { token } = response.data;
        wx.setStorageSync('token', token);
      },
    });
  },
});
```

**关键：**

- `appid` 和 `secret` 只能放后端，不能写在小程序里。
- `code` 只能用一次，5 分钟有效。
- `session_key` 不能下发给前端。
- 用 `wx.checkSession` 检查登录态。
- token 放请求头，过期要重新登录。

### 9.5 支付（了解） ⭐

```text
1. 前端请求后端创建订单
2. 后端调用微信统一下单，拿到 prepay_id，签名
3. 后端把 timeStamp/nonceStr/package/signType/paySign 返回前端
4. 前端调用 wx.requestPayment
5. 微信回调后端，后端验签、更新订单状态
```

```js
wx.requestPayment({
  timeStamp: '...',
  nonceStr: '...',
  package: 'prepay_id=...',
  signType: 'RSA',
  paySign: '...',
  success() {},
  fail() {},
});
```

## 12. 性能优化 ⭐⭐⭐

### 12.1 setData 是最大的性能点

`setData` 会把数据从逻辑层传到视图层，还要序列化。数据越大、越频繁，越卡。

```js
// 差：每次改整个列表
this.setData({ list: newList });

// 好：只改需要变的字段（路径更新）
this.setData({
  'list[0].title': '新标题',
  'list[0].price': 199,
});

// 好：只传变化的部分
this.setData({ loading: false });
```

优化原则：

1. **能少传就少传**：不要把所有 data 都 setData。
2. **不要频繁 setData**：滚动、输入时做防抖/节流。
3. **不要传大对象**：列表数据分页，图片用 URL。
4. **不要在 `onPageScroll` 里 setData**。
5. **合并更新**：多次修改一次性 setData。
6. **避免setData回调里再setData**，容易链式卡顿。

### 12.2 长列表

- 分页加载，不要一次渲染几千条。
- 使用 `recycle-view`（官方扩展组件）或虚拟列表。
- `wx:key` 用稳定 id。
- 列表项组件化，减少节点数。

### 12.3 图片

- 使用 CDN + 合适尺寸，不要直接加载原图。
- `lazy-load` 懒加载。
- 使用 WebP（注意兼容）。
- 固定宽高，避免布局抖动。

### 12.4 启动优化

- 分包 + 预下载。
- `lazyCodeLoading: "requiredComponents"` 按需注入。
- 减少启动时的同步请求。
- 首屏骨架屏。
- 图片、字体预加载。
- 避免在 `onLaunch` 里做重任务。

### 12.5 渲染

- 减少节点层级。
- 少用 `wx:if` 频繁切换大块内容（可用 `hidden`）。
- 避免过深的 `wx:for` 嵌套。
- 使用 Skyline 渲染引擎（如项目支持）提升性能，但要注意兼容性。

```js
const { fetchGoods } = require('../../data/mock');

Page({
  data: {
    keyword: '',
    list: [],
    loading: true,
    error: '',
  },

  onLoad() {
    this.timer = null;
    this.unloaded = false;
    this.load();
  },

  onUnload() {
    // 页面卸载时清理定时器，避免回调里 setData
    this.unloaded = true;
    if (this.timer) clearTimeout(this.timer);
  },

  // 输入：300ms 防抖
  onInput(e) {
    const keyword = e.detail.value;
    this.setData({ keyword });

    if (this.timer) clearTimeout(this.timer);
    this.timer = setTimeout(() => {
      this.load();
    }, 300);
  },

  // 回车：立即搜索
  onSearch() {
    if (this.timer) clearTimeout(this.timer);
    this.load();
  },

  // 清空：立即刷新全部
  onClear() {
    this.setData({ keyword: '' });
    if (this.timer) clearTimeout(this.timer);
    this.load();
  },

  // 加载列表
  async load() {
    this.setData({ loading: true, error: '' });

    try {
      const list = await fetchGoods(this.data.keyword);
      if (this.unloaded) return;
      this.setData({ list });
    } catch (err) {
      if (this.unloaded) return;
      this.setData({ error: err.message || '加载失败' });
    } finally {
      if (!this.unloaded) {
        this.setData({ loading: false });
      }
    }
  },

  // 下拉刷新
  onPullDownRefresh() {
    this.load().finally(() => wx.stopPullDownRefresh());
  },

  // 点击商品：跳详情
  onSelect(e) {
    const { id } = e.detail;
    wx.navigateTo({
      url: `/pages/detail/detail?id=${id}`,
    });
  },
});
```

## 16. 面试高频题

### Q1：小程序的双线程模型是什么？ ⭐⭐⭐

**答：** 小程序分逻辑层和视图层。逻辑层运行在 JSCore 里，执行 JS、处理业务和 setData；视图层运行在 WebView（或 Skyline）里，负责渲染 WXML/WXSS。两层通过微信客户端通信，setData 把数据从逻辑层序列化后传到视图层，事件从视图层传回逻辑层。好处是隔离、安全、避免 JS 阻塞渲染；代价是 setData 有通信和序列化开销。

### Q2：`setData` 为什么慢？怎么优化？ ⭐⭐⭐

**答：** setData 要把数据序列化，通过通信层从逻辑层传到视图层，再触发渲染。数据越大、调用越频繁越慢。优化：只传变化的数据；用路径更新 `this.setData({ 'list[0].title': 'x' })`；合并多次更新；列表分页；不要在 onPageScroll 里 setData；避免传大对象；长列表用虚拟列表。

### Q3：`onLoad`、`onShow`、`onReady` 的区别？ ⭐⭐⭐

**答：** onLoad 页面加载时执行一次，可接收路由参数，适合初始化；onShow 每次页面显示都执行，适合刷新状态；onReady 首次渲染完成执行一次，适合操作节点/动画。onHide 页面隐藏，onUnload 页面卸载。

### Q4：`wx:if` 和 `hidden` 的区别？ ⭐⭐

**答：** wx:if 条件为假时会销毁节点，切换开销大但初始不渲染；hidden 始终渲染，只是控制显示隐藏，切换快但占节点。频繁切换用 hidden，不常显示用 wx:if。

### Q5：小程序路由有哪些？有什么区别？ ⭐⭐⭐

**答：** navigateTo 保留当前页压栈，最多 10 层；redirectTo 关闭当前页替换；switchTab 只能跳 tabBar 页；reLaunch 关闭所有页面打开指定页；navigateBack 返回。参数拼在 URL 上，复杂数据用全局变量/缓存/EventChannel。

### Q6：小程序怎么登录？ ⭐⭐⭐

**答：** 前端 wx.login 拿 code，发给后端；后端用 appid/secret/code 调 code2session 换 openid 和 session_key，生成自定义 token 返回；前端存 token，后续请求带在 header。secret 不能放前端，session_key 不能下发，token 过期要重新登录。

### Q7：小程序怎么分包？为什么分包？ ⭐⭐

**答：** 主包有大小限制，代码多时要拆成主包 + 子包。主包放启动页、tabBar 和公共资源；子包放详情、个人中心等低频页面；app.json 里配 subpackages，跳转路径带分包 root；preloadRule 可以预下载。还有独立分包和分包异步化。

### Q8：小程序和 H5 的区别？ ⭐⭐⭐

**答：** 小程序运行在微信里，用 WXML/WXSS，逻辑层和视图层双线程，通过 wx.request 请求并需要配置合法域名，能用微信登录/支付/扫码等原生能力，发布要审核；H5 用 HTML/CSS/JS，浏览器渲染，部署即上线，原生能力弱，性能受 WebView 限制。

### Q9：自定义组件怎么传值和通信？ ⭐⭐

**答：** 父传子用 properties；子传父用 triggerEvent 触发自定义事件，父组件 bind:事件名 接收；组件内部用 setData 更新；跨组件/页面可以用全局数据、缓存、EventChannel 或状态管理。

### Q10：小程序性能优化有哪些？ ⭐⭐⭐

**答：** setData 优化（少传、路径更新、合并、防抖）；长列表分页/虚拟列表；图片懒加载和压缩；分包 + 预下载 + 按需注入；减少节点层级；避免 onPageScroll 里 setData；首屏骨架；启动时减少同步任务；必要时用 Skyline。

### Q11：小程序的 `rpx` 是什么？ ⭐⭐

**答：** 响应式单位，750rpx 等于屏幕宽度，1rpx = 屏幕宽度/750。设计稿 750px 时，设计稿多少 px 就写多少 rpx，能自动适配不同屏幕宽度。

### Q12：小程序怎么做支付？ ⭐⭐

**答：** 前端请求后端创建订单；后端调微信统一下单，拿 prepay_id 并签名；前端用 wx.requestPayment 发起支付；微信回调后端，后端验签并更新订单。金额、签名、订单状态都以后端为准。

### Q13：小程序和 React 的区别？ ⭐⭐

**答：** React 用 JSX、虚拟 DOM、Hooks、react-router；小程序用 WXML/WXSS、setData、Page/Component、wx.navigateTo。小程序是双线程，逻辑层不能直接操作 DOM；React 在浏览器里操作 DOM。跨端框架如 Taro 可以把 React 编译成小程序。

### Q14：小程序为什么不能直接操作 DOM？ ⭐⭐

**答：** 因为逻辑层运行在 JSCore，没有 DOM/BOM，视图层在 WebView 里，两层隔离。只能通过 setData 更新视图，通过事件从视图层传回逻辑层。这是为了保证安全和性能隔离。
