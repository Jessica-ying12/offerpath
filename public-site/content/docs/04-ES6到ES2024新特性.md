# 04 · ES6 到 ES2024 新特性

> 目标：看懂现代前端代码；面试能说出 ES6 的核心特性；理解“语法转换”和“API 补丁”的区别。
>
> 说明：ES6 = ES2015。之后每年发布一版，所以现在叫 ES2015/ES2016/.../ES2024。本文用“ES6+”统称。

---

## 1. 为什么要有 ES6

ES5 时代写复杂项目很痛苦：

```js
// ES5 的痛
var self = this;
var list = [1, 2, 3];
var doubled = list.map(function (n) {
  return n * 2;
});

function getUser(id) {
  return fetch('/api/user/' + id)
    .then(function (res) {
      return res.json();
    })
    .then(function (data) {
      return data;
    });
}
```

ES6 之后：

```js
const doubled = [1, 2, 3].map((n) => n * 2);

const getUser = async (id) => {
  const res = await fetch(`/api/user/${id}`);
  return res.json();
};
```

## 2. `let` / `const` 与块级作用域 ⭐⭐⭐

```js
{
  let a = 1;
  const b = 2;
  var c = 3;
}
// console.log(a); // ReferenceError
// console.log(b); // ReferenceError
console.log(c);   // 3
```

- `let`：块级作用域，可重新赋值。
- `const`：块级作用域，不能重新赋值；对象内容可以改。
- TDZ（暂时性死区）：声明前访问会报错。

```js
const user = { name: 'Tom' };
user.name = 'Jerry'; // 可以
// user = {};        // TypeError

// 想真正冻结对象
const frozen = Object.freeze({ name: 'Tom' });
// frozen.name = 'Jerry'; // 静默失败（严格模式报错）
```

## 3. 解构赋值 ⭐⭐⭐

### 3.1 数组解构

```js
const [a, b] = [1, 2];
console.log(a, b); // 1 2

// 跳过
const [, second] = [1, 2, 3];
console.log(second); // 2

// 剩余
const [first, ...rest] = [1, 2, 3, 4];
console.log(first); // 1
console.log(rest);  // [2, 3, 4]

// 默认值：只有 undefined 才用默认值
const [x = 10] = [];
console.log(x); // 10

// 交换变量
let m = 1;
let n = 2;
[m, n] = [n, m];
console.log(m, n); // 2 1
```

### 3.2 对象解构

```js
const user = { name: 'Tom', age: 18, address: { city: '上海' } };

const { name, age } = user;

// 重命名
const { name: userName } = user;
console.log(userName); // Tom

// 默认值
const { gender = 'unknown' } = user;
console.log(gender); // unknown

// 嵌套
const { address: { city } } = user;
console.log(city); // 上海

// 剩余属性
const { name: n2, ...others } = user;
console.log(others); // { age: 18, address: {...} }
```

### 3.3 函数参数解构

```js
function createUser({ name, age = 18, tags = [] }) {
  return { name, age, tags };
}

createUser({ name: 'Tom' }); // { name: 'Tom', age: 18, tags: [] }

// 注意：不传参数会报错
// createUser(); // TypeError: Cannot destructure property 'name' of undefined

// 安全写法
function createUser2({ name, age = 18 } = {}) {
  return { name, age };
}
createUser2(); // { name: undefined, age: 18 }
```

### 3.4 解构的常见用途

```js

const { code, data, message } = response;

// 2. 交换变量
[a, b] = [b, a];

  return [100, 200];
}

// 4. 导入模块
```

## 5. 箭头函数 ⭐⭐⭐

```js
// 普通函数
const add1 = function (a, b) {
  return a + b;
};

// 箭头函数
const add2 = (a, b) => a + b;

// 单个参数可以省略括号
const double = n => n * 2;

// 返回对象要加括号
const create = (name) => ({ name });

// 多行要写 return
const calc = (a, b) => {
  const sum = a + b;
  return sum * 2;
};
```

### 5.1 和普通函数的区别

| 特性 | 普通函数 | 箭头函数 |
|---|---|---|
| `this` | 调用时决定 | 定义时外层作用域的 this |
| `arguments` | 有 | 没有（用 rest 参数） |
| `new` | 可以 | 不可以 |
| `prototype` | 有 | 没有 |
| `yield` | 可以 | 不可以 |
| 适合场景 | 对象方法、构造函数 | 回调、短函数 |

```js
const obj = {
  name: 'Tom',
  say() {
    console.log(this.name); // Tom
  },
  sayArrow: () => {
    console.log(this.name); // undefined（外层不是 obj）
  },
};
```

**结论：对象方法、需要动态 this 的地方用普通函数；回调、数组方法用箭头函数。**

### 5.2 回调里的 this

```js
// 旧写法：用 self 保存 this
const timer = {
  seconds: 0,
  start() {
    const self = this;
    setInterval(function () {
      self.seconds++;
    }, 1000);
  },
};

// 新写法：箭头函数
const timer2 = {
  seconds: 0,
  start() {
    setInterval(() => {
      this.seconds++;
    }, 1000);
  },
};
```

## 6. 参数增强：默认、剩余、展开 ⭐⭐⭐

```js
// 默认参数
function greet(name = '访客', greeting = '你好') {

// 浅拷贝
const copy = { ...obj };
const copyArr = [...arr];

const merged = { ...obj, ...obj2 }; // 后面的覆盖前面的

// 转数组
const nodeList = document.querySelectorAll('.item');
const list = [...nodeList];
```

### 8.5 ESM 的特点

- 静态分析：编译时就能确定依赖，支持 tree shaking。
- 导出是**实时绑定**：

```js
// counter.js
export let count = 0;
export function increment() {
  count++;
}

// main.js
import { count, increment } from './counter.js';
console.log(count); // 0
increment();
console.log(count); // 1（如果是 CommonJS 的值拷贝，这里还是 0）
```

- 模块顶层 `this` 是 `undefined`。
- 默认严格模式。
- 支持顶层 await（ES2022）。
- 浏览器里 `<script type="module">` 默认 defer。

## 9. class ⭐⭐⭐

### 9.1 基本语法

```js
class Person {
  // 实例字段（ES2022）
  name = 'unknown';
  age = 0;

  // 私有字段（ES2022）：只能在类内部访问
  #secret = 'hidden';

  // 静态字段
  static species = 'human';

  constructor(name, age) {
    this.name = name;
    this.age = age;
  }

  // 实例方法
  say() {
    console.log(`${this.name}, ${this.age}`);
  }

  // 私有方法
  #getSecret() {
    return this.#secret;
  }

  // 静态方法
  static create(name, age) {
    return new Person(name, age);
  }

  // getter
  get info() {
    return `${this.name} (${this.age})`;
  }

  // 静态代码块（ES2022）
  static {
    console.log('类初始化时执行一次');
  }
}

const p = new Person('Tom', 18);
p.say();
console.log(Person.species);
console.log(Person.create('Jerry', 20).info);
// console.log(p.#secret); // SyntaxError，外部不能访问
```

### 9.2 继承

```js
class Animal {
  constructor(name) {
    this.name = name;
  }

  speak() {
    console.log(`${this.name} makes a sound`);
  }

  static create(name) {
    return new this(name); // this 指向调用它的子类
  }
}

class Dog extends Animal {
  constructor(name, breed) {
    super(name); // 必须先调用 super，才能使用 this
    this.breed = breed;
  }

  speak() {
    super.speak(); // 调用父类方法
    console.log('woof');
  }
}

const dog = new Dog('Wang', 'Corgi');
dog.speak();
console.log(dog instanceof Animal); // true
console.log(dog instanceof Dog);    // true
```

### 9.3 class 和构造函数的区别

| 维度 | 构造函数 | class |
|---|---|---|
| 调用 | 可以直接调用 | 必须 `new`，否则报错 |
| 提升 | 函数声明提升 | 有 TDZ，不能提前用 |
| 严格模式 | 默认不严格 | 内部自动严格 |
| 方法可枚举 | 是 | 否 |
| 继承 | 手动原型链 | `extends`/`super` |
| 本质 | — | 原型继承的语法糖 |

## 10. Symbol、迭代器、生成器 ⭐

### 10.1 Symbol

唯一值，常用来做对象私有键、避免命名冲突。

```js
const id = Symbol('id');
const user = {
  [id]: 1,
  name: 'Tom',
};

console.log(user[id]); // 1
console.log(Object.keys(user)); // ['name']，Symbol 键不会被遍历
console.log(Reflect.ownKeys(user)); // ['name', Symbol(id)]

// 内置 Symbol
Symbol.iterator;
Symbol.asyncIterator;
Symbol.toStringTag;
```

### 10.2 迭代器

可迭代对象实现了 `Symbol.iterator` 方法，返回一个迭代器：

```js
const list = [1, 2, 3];
const iterator = list[Symbol.iterator]();

console.log(iterator.next()); // { value: 1, done: false }
console.log(iterator.next()); // { value: 2, done: false }
console.log(iterator.next()); // { value: 3, done: false }
console.log(iterator.next()); // { value: undefined, done: true }
```

```js
// 自定义可迭代对象
const range = {
  from: 1,
  to: 3,
  [Symbol.iterator]() {
    let current = this.from;
    const last = this.to;
    return {
      next() {
        return current <= last
          ? { value: current++, done: false }
          : { value: undefined, done: true };
      },
    };
  },
};

console.log([...range]); // [1, 2, 3]
for (const n of range) console.log(n);
```

### 10.3 生成器

```js
function* idGenerator() {
  let id = 1;
  while (true) {
    yield id++;
  }
}

const gen = idGenerator();
console.log(gen.next().value); // 1
console.log(gen.next().value); // 2

// 生成器实现迭代器
function* rangeGenerator(from, to) {
  for (let i = from; i <= to; i++) {
    yield i;
  }
}
console.log([...rangeGenerator(1, 3)]); // [1, 2, 3]
```

用途：惰性序列、异步流程（async/await 的前身）、无限列表。

## 11. Map / Set / WeakMap / WeakSet ⭐⭐

### 11.1 Map

键可以是任意类型，保持插入顺序。

```js
const map = new Map();
map.set('name', 'Tom');
map.set(1, 'one');
map.set({ id: 1 }, 'object key');

map.get('name'); // 'Tom'
map.has('name'); // true
map.delete('name');
map.size;
map.clear();

// 遍历
map.forEach((value, key) => console.log(key, value));
for (const [key, value] of map) {}
```

### 11.2 Set

值的集合，自动去重。

```js
const set = new Set([1, 2, 2, 3]);
console.log([...set]); // [1, 2, 3]
set.add(4);
set.has(2);
set.delete(1);
set.size;
```

### 11.3 WeakMap / WeakSet

- 键必须是对象。
- 弱引用：键对象没有其他引用时，可以被垃圾回收，不会造成内存泄漏。
- 不可遍历。

```js
const cache = new WeakMap();

function process(obj) {
  if (cache.has(obj)) return cache.get(obj);
  const result = expensive(obj);
  cache.set(obj, result);
  return result;
}

// 用 WeakMap 存私有数据
const privateData = new WeakMap();
class User {
  constructor(name) {
    privateData.set(this, { name });
  }
  getName() {
    return privateData.get(this).name;
  }
}
```

| 结构 | 键类型 | 可遍历 | 垃圾回收 |
|---|---|---|---|
| Map | 任意 | 是 | 强引用 |
| WeakMap | 对象 | 否 | 弱引用 |
| Set | 任意 | 是 | 强引用 |
| WeakSet | 对象 | 否 | 弱引用 |

## 12. Promise 与 async/await（ES6/ES2017） ⭐⭐⭐

### 12.1 Promise 基础

```js
const p = new Promise((resolve, reject) => {
  // executor 同步执行
  if (ok) resolve(value);
  else reject(error);
});

p.then(onFulfilled, onRejected)
 .catch(onRejected)
 .finally(onFinally);
```

### 12.2 链式调用

```js
fetch('/api/user')
  .then((res) => {
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
    return res.json(); // 返回 Promise，下一个 then 等它
  })
  .then((user) => fetch(`/api/orders/${user.id}`))
  .then((res) => res.json())
  .then((orders) => console.log(orders))
  .catch((err) => console.error(err))
  .finally(() => console.log('结束'));
```

### 12.3 async/await

```js
async function loadOrders() {
  try {
    const userRes = await fetch('/api/user');
    const user = await userRes.json();
    const orderRes = await fetch(`/api/orders/${user.id}`);
    return await orderRes.json();
  } catch (err) {
    console.error(err);
    throw err;
  }
}
```

### 12.4 错误处理

```js
// 每个 await 都可能抛错，最好统一 try/catch
async function safeRequest() {
  try {
    const res = await fetch('/api');
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
    return await res.json();
  } catch (err) {
    // 网络错误、HTTP 错误、JSON 解析错误都会到这里
    return null;
  }
}
```

### 12.5 并发

```js
// 串行：3 秒
const a = await requestA();
const b = await requestB();
const c = await requestC();

// 并行：1 秒（假设各 1 秒）
const [a2, b2, c2] = await Promise.all([requestA(), requestB(), requestC()]);
```

## 13. Proxy 与 Reflect ⭐

`Proxy` 可以拦截对象的操作，Vue 3 的响应式就是基于它。

```js
const target = { name: 'Tom', age: 18 };

const proxy = new Proxy(target, {
  get(obj, key) {
    console.log('读取', key);
    return obj[key];
  },
  set(obj, key, value) {
    console.log('设置', key, value);
    if (key === 'age' && value < 0) {
      throw new Error('年龄不能为负');
    }
    obj[key] = value;
    return true; // 严格模式下必须返回 true
  },
  has(obj, key) {
    return key in obj;
  },
});

proxy.name;        // 读取 name → 'Tom'
proxy.age = 20;    // 设置 age 20
// proxy.age = -1; // 抛错
```

`Reflect` 提供操作对象的默认行为：

```js
Reflect.get(obj, 'name');
Reflect.set(obj, 'age', 20);
Reflect.has(obj, 'name');
Reflect.ownKeys(obj);
Reflect.construct(Ctor, args);
```

在 Proxy 里用 `Reflect` 可以保持默认行为：

```js
const proxy2 = new Proxy(target, {
  get(obj, key, receiver) {
    return Reflect.get(obj, key, receiver);
  },
});
```

```js
  #secret = 'hidden';  // 私有字段
  #privateMethod() {}
  static { /* 静态初始化块 */ }
}

// at()：支持负索引
[1, 2, 3].at(-1); // 3
'abc'.at(-1);     // 'c'

// Object.hasOwn
Object.hasOwn({ a: 1 }, 'a'); // true

// Error cause
throw new Error('请求失败', { cause: originalError });
```

### ES2023

```js
[1, 2, 3].findLast((n) => n < 3);      // 2
[1, 2, 3].findLastIndex((n) => n < 3); // 1

// 不改原数组的排序/反转/替换
[3, 1, 2].toSorted();    // [1, 2, 3]
[1, 2, 3].toReversed();  // [3, 2, 1]
[1, 2, 3].toSpliced(0, 1); // [2, 3]
[1, 2, 3].with(1, 9);    // [1, 9, 3]
```

### ES2024（较新，注意兼容性）

```js
// Object.groupBy
const grouped = Object.groupBy([1, 2, 3, 4], (n) => (n % 2 ? 'odd' : 'even'));
// { odd: [1, 3], even: [2, 4] }

// Map.groupBy
const mapGrouped = Map.groupBy(list, (item) => item.type);

// Promise.withResolvers
const { promise, resolve, reject } = Promise.withResolvers();

// 正则 v 标志（Unicode 集合）
/[\p{Letter}--[a-z]]/v;
```

> ES2025 附近还有 `Set.prototype.union/intersection/difference`、Iterator Helpers、`Promise.try` 等，浏览器支持较新，项目里用之前先查兼容性。

## 15. 语法转换 vs Polyfill ⭐⭐⭐

很多人分不清 Babel 和 core-js。

### 15.1 Babel 做什么

Babel 负责**语法转换**：把新语法改写成旧语法。

```js
// 源码
const add = (a, b) => a + b;

// Babel 转成 ES5
var add = function add(a, b) {
  return a + b;
};
```

箭头函数、class、解构、模板字符串、可选链，都可以转。

### 15.2 Polyfill 做什么

有些新东西不是语法，而是**新 API**，Babel 转不了：

```js
Promise;
Array.prototype.includes;
Object.assign;
String.prototype.padStart;
fetch;
```

这些需要 `core-js` 或浏览器原生支持。Polyfill 会在全局补上实现。

```js
// core-js 会做类似这样的事
if (!Array.prototype.includes) {
  Array.prototype.includes = function (value) {
    return this.indexOf(value) !== -1;
  };
}
```

### 15.3 Babel 配置

```bash
npm i -D @babel/core @babel/preset-env babel-loader
npm i core-js
```

```js
// babel.config.js
module.exports = {
  presets: [
    [
      '@babel/preset-env',
      {
        // 根据 browserslist 自动决定要转哪些语法
        targets: '> 0.5%, last 2 versions, not dead',
        // 按需引入 polyfill，避免全量引入
        useBuiltIns: 'usage',
        corejs: '3.37',
      },
    ],
  ],
};
```

```json
// package.json
{
  "browserslist": ["> 0.5%", "last 2 versions", "not dead"]
}
```

### 15.4 面试答法

> Babel 主要做语法转换，比如把箭头函数、class、可选链转成旧浏览器能跑的代码；但像 Promise、Array.prototype.includes 这种新 API，语法转换解决不了，需要 core-js 这样的 polyfill 在运行时补齐。`@babel/preset-env` 可以结合 browserslist 按目标浏览器决定转换范围，`useBuiltIns: 'usage'` 可以按需引入 polyfill。

## 16. 现代 JS 写法对照

### 16.1 取对象属性

```js
// 旧
var name = user && user.name;
var city = user && user.address && user.address.city;

// 新
const name = user?.name;
const city = user?.address?.city;
```

### 16.2 默认值

```js
// 旧：0 和 '' 也会被替换
var count = input || 10;

// 新：只有 null/undefined 才替换
const count = input ?? 10;
```

### 16.3 交换变量

```js
let a = 1, b = 2;
[a, b] = [b, a];
```

### 16.4 对象合并

```js
// 旧
var merged = Object.assign({}, a, b);

// 新
const merged = { ...a, ...b };
```

### 16.5 数组去重

```js
// 旧
var unique = arr.filter(function (item, index) {
  return arr.indexOf(item) === index;
});

// 新
const unique = [...new Set(arr)];
```

### 16.6 条件属性

```js
// 旧
var obj = { name: 'Tom' };
if (isVip) obj.level = 'VIP';

// 新
const obj = {
  name: 'Tom',
  ...(isVip ? { level: 'VIP' } : {}),
};
```

### 16.7 async 请求

```js
// 旧
function load() {
  return fetch('/api')
    .then(function (res) { return res.json(); })
    .then(function (data) { return data; })
    .catch(function (err) { console.error(err); });
}

// 新
async function load() {
  try {
    const res = await fetch('/api');
    return await res.json();
  } catch (err) {
    console.error(err);
  }
}
```

## 17. 面试高频题

### Q1：ES6 有哪些新特性？ ⭐⭐⭐

**答：** 主要说这几类：

- 变量：`let/const`、块级作用域。
- 函数：箭头函数、默认参数、剩余参数、展开。
- 语法：解构、模板字符串、对象简写、计算属性。
- 面向对象：`class`、`extends`、`super`。
- 异步：`Promise`、`async/await`（ES2017）。
- 数据结构：`Map`、`Set`、`WeakMap`、`WeakSet`。
- 模块：`import/export`。
- 其他：`Symbol`、迭代器、生成器、`Proxy/Reflect`。

### Q2：箭头函数和普通函数的区别？ ⭐⭐⭐

**答：** 箭头函数没有自己的 this，取定义时外层作用域的 this；没有 arguments，用 rest 参数；不能 new，没有 prototype；不能用作生成器。适合回调和短函数，不适合对象方法和需要动态 this 的场景。

### Q3：`let`、`const`、`var` 的区别？ ⭐⭐⭐

**答：** var 函数作用域、提升且初始化为 undefined、可重复声明；let/const 块级作用域、有 TDZ、不能重复声明；const 不能重新赋值，但对象内容可变。

### Q4：ES Module 和 CommonJS 的区别？ ⭐⭐⭐

**答：** ESM 是编译时静态分析、异步加载、导出实时绑定、支持 tree shaking 和顶层 await；CommonJS 是运行时同步加载、导出值拷贝、不支持 tree shaking。ESM 的 this 是 undefined，CommonJS 的 this 是 module.exports。

### Q5：`??` 和 `||` 的区别？ ⭐⭐⭐

**答：** `||` 在左边是假值时取右边，包括 `0`、`''`、`false`；`??` 只在左边是 `null` 或 `undefined` 时取右边。所以 `0 ?? 10` 是 0，`0 || 10` 是 10。

### Q6：可选链有什么坑？ ⭐⭐

**答：** 它只对紧挨着的那一层生效。`obj?.a.b` 里如果 `obj.a` 是 null，访问 `.b` 仍然报错，要写 `obj?.a?.b`。另外可选链不能用于赋值左侧。

### Q7：`class` 和构造函数的区别？ ⭐⭐

**答：** class 必须用 new 调用；内部自动严格模式；方法不可枚举；有 TDZ；继承用 extends/super。本质还是原型继承的语法糖。

### Q8：`Map` 和普通对象有什么区别？ ⭐⭐

**答：** Map 的键可以是任意类型（对象、函数），保持插入顺序，有 size 属性，可直接迭代，频繁增删性能更好；普通对象的键只能是字符串/Symbol，还会有原型链上的属性干扰。需要字典且键不是字符串时用 Map。

### Q9：`WeakMap` 有什么用？ ⭐⭐

**答：** 键必须是对象，弱引用，键没有其他引用时可以被回收，不会阻止垃圾回收；不可遍历。常用来给对象存私有数据、做缓存、避免内存泄漏。

### Q10：Babel 和 polyfill 的区别？ ⭐⭐⭐

**答：** Babel 转语法（箭头、class、可选链），polyfill 补 API（Promise、includes）。Babel 用 preset-env 按 browserslist 转语法，core-js 按需补 API。

### Q11：什么是 tree shaking？ ⭐⭐

**答：** 打包时删除没有被使用的 ESM 导出代码。它依赖静态的 import/export、没有副作用（`sideEffects: false`），CommonJS 因为运行时加载，通常无法 tree shaking。

### Q12：顶层 await 是什么？ ⭐⭐

**答：** ES2022 特性，允许在 ES Module 顶层直接写 await，模块会等异步完成后再执行依赖它的模块。只能用于 module，不能用于 CommonJS 和普通 script。
