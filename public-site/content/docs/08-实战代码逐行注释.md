# 08 · 实战代码逐行注释

> 目标：把前面的知识变成“能写出来”的能力。跟着敲完两个完整项目，再对照三端写法，最后用报错字典自查。
>
> 建议：**不要复制粘贴**，一行一行敲；每敲完一段就刷新页面看效果。

## 1. 写代码的 7 步法

以“商品搜索列表”为例。

### 第 1 步：画界面

在纸上画三个区域：

```text
┌──────────────────────────┐
│  搜索框                   │
├──────────────────────────┤
│  商品卡片  商品卡片        │
│  商品卡片  商品卡片        │
├──────────────────────────┤
│  底部导航                 │
└──────────────────────────┘
```

### 第 2 步：拆组件

- `SearchBar`：输入 + 清空 + 搜索
- `ProductList`：列表容器
- `ProductCard`：单个商品
- `EmptyState`：空状态
- `ErrorState`：错误 + 重试
- `Loading`：加载中

### 第 3 步：定数据

```js
const product = {
  id: 1,
  title: '无线耳机',
  price: 199,
  cover: 'https://example.com/a.jpg',
  tags: ['包邮'],
};
```

页面状态：

```js
{
  keyword: '',      // 搜索词
  list: [],         // 商品列表
  loading: false,   // 是否加载中
  error: '',        // 错误信息
}
```

### 第 4 步：先写死的

先用 2 条假数据把布局调好，不要一上来就请求接口。

### 第 5 步：写交互

- 输入 → 更新 keyword。
- 停止输入 300ms → 请求。
- 请求成功 → 更新 list。
- 请求失败 → 显示 error + 重试。
- 点击卡片 → 跳详情。

### 第 6 步：补边界

- 加载中
- 空列表
- 请求失败
- 快速输入（取消旧请求）
- 重复点击
- 长标题
- 图片加载失败

### 第 7 步：自测 + 重构

- 断网试试。
- 输入空格、超长文本、特殊字符。
- 把重复代码抽成函数。
- 给关键逻辑写注释（解释为什么）。

```html
  <script>
    // ===== 1. 常量与 DOM 引用 =====
    const STORAGE_KEY = 'todos'; // localStorage 的 key

    const form = document.getElementById('todo-form');
    const input = document.getElementById('todo-input');
    const filters = document.getElementById('filters');
    const list = document.getElementById('todo-list');
    const summary = document.getElementById('summary');

    // ===== 2. 应用状态 =====
    // todos: [{ id, title, done }]
    let todos = loadTodos();

    // 当前筛选：all / active / done
    let filter = 'all';

    // ===== 3. 工具函数 =====

    // 生成一个足够唯一的 id（不依赖 crypto，file:// 也能用）
    function createId() {
      return `${Date.now().toString(36)}-${Math.random().toString(36).slice(2, 8)}`;
    }

    // 从 localStorage 读取；任何异常都回退到空数组
    function loadTodos() {
      try {
        const raw = localStorage.getItem(STORAGE_KEY);
        if (!raw) return [];

        const parsed = JSON.parse(raw);
        return Array.isArray(parsed) ? parsed : [];
      } catch (err) {
        console.warn('读取本地数据失败，已重置', err);
        return [];
      }
    }

    // 写入 localStorage
    function saveTodos() {
      localStorage.setItem(STORAGE_KEY, JSON.stringify(todos));
    }

    // 根据当前筛选条件计算要显示的列表
    function getVisibleTodos() {
      if (filter === 'active') return todos.filter((todo) => !todo.done);
      if (filter === 'done') return todos.filter((todo) => todo.done);
      return todos;
    }

    // ===== 4. 渲染 =====

    function render() {
      const visibleTodos = getVisibleTodos();

      // 清空旧内容。这里清空是安全的，因为下面所有内容都用 textContent 写入。
      list.innerHTML = '';

      // 空状态
      if (visibleTodos.length === 0) {
        const empty = document.createElement('li');
        empty.className = 'empty';
        empty.textContent =
          filter === 'all' ? '还没有待办，先添加一条吧' : '这个分类下没有待办';
        list.appendChild(empty);
      } else {
        // 用 DocumentFragment 批量插入，减少浏览器重排
        const fragment = document.createDocumentFragment();

        visibleTodos.forEach((todo) => {
          const li = document.createElement('li');
          li.className = todo.done ? 'item is-done' : 'item';
          li.dataset.id = todo.id; // 事件委托时用来找 id

          // 左侧：复选框 + 标题（label 包起来，点文字也能切换）
          const label = document.createElement('label');
          label.className = 'item__main';

          const checkbox = document.createElement('input');
          checkbox.type = 'checkbox';
          checkbox.checked = todo.done;
          checkbox.className = 'item__checkbox';
          checkbox.setAttribute(
            'aria-label',
            todo.done ? `将「${todo.title}」标记为未完成` : `将「${todo.title}」标记为已完成`
          );

          const title = document.createElement('span');
          title.className = 'item__title';
          title.textContent = todo.title; // 用 textContent，防止 XSS

          label.append(checkbox, title);

          // 右侧：删除按钮
          const deleteBtn = document.createElement('button');
          deleteBtn.type = 'button';
          deleteBtn.className = 'item__delete';
          deleteBtn.textContent = '删除';
          deleteBtn.setAttribute('aria-label', `删除「${todo.title}」`);

          li.append(label, deleteBtn);
          fragment.appendChild(li);
        });

        list.appendChild(fragment);
      }

      // 统计
      const doneCount = todos.filter((todo) => todo.done).length;
      summary.textContent = `共 ${todos.length} 项，已完成 ${doneCount} 项，未完成 ${
        todos.length - doneCount
      } 项`;

      // 更新筛选按钮的激活状态
      document.querySelectorAll('.filters__btn').forEach((btn) => {
        const isActive = btn.dataset.filter === filter;
        btn.classList.toggle('is-active', isActive);
        btn.setAttribute('aria-pressed', String(isActive));
      });
    }

    // ===== 5. 事件处理 =====

    // 添加
    form.addEventListener('submit', (event) => {
      event.preventDefault(); // 阻止表单默认刷新页面

      const title = input.value.trim();
      if (!title) {
        input.focus();
        return;
      }

      // 新待办放到最前面
      todos = [{ id: createId(), title, done: false }, ...todos];

      input.value = '';
      saveTodos();
      render();
      input.focus(); // 连续添加时保持焦点
    });

    // 切换完成状态：用 change 事件，键盘操作也能触发
    list.addEventListener('change', (event) => {
      const checkbox = event.target;
      if (!checkbox.matches('input[type="checkbox"]')) return;

      const li = checkbox.closest('li[data-id]');
      if (!li) return;

      const id = li.dataset.id;

      // 不要直接改原对象，创建新数组/新对象
      todos = todos.map((todo) =>
        todo.id === id ? { ...todo, done: checkbox.checked } : todo
      );

      saveTodos();
      render();
    });

    // 删除：事件委托，绑在 ul 上
    list.addEventListener('click', (event) => {
      const deleteBtn = event.target.closest('.item__delete');
      if (!deleteBtn) return;

      const li = deleteBtn.closest('li[data-id]');
      if (!li) return;

      todos = todos.filter((todo) => todo.id !== li.dataset.id);

      saveTodos();
      render();
    });

    // 筛选
    filters.addEventListener('click', (event) => {
      const btn = event.target.closest('button[data-filter]');
      if (!btn) return;

      filter = btn.dataset.filter;
      render();
    });

    // ===== 6. 首次渲染 =====
    render();
  </script>
</body>
</html>
```

### 这个项目练到了什么

| 知识点 | 用在哪里 |
|---|---|
| DOM 查询 | `getElementById` |
| 创建/插入节点 | `createElement`、`append`、`DocumentFragment` |
| 事件委托 | 列表的 change/click 绑在 ul 上 |
| 事件对象 | `event.target`、`closest`、`dataset` |
| 数组方法 | `map`、`filter`、`unshift`（这里用展开代替） |
| 对象不可变更新 | `{ ...todo, done }` |
| localStorage | 读写 + 异常处理 |
| XSS 防护 | 用 `textContent` 而不是 `innerHTML` 拼用户输入 |
| 无障碍 | `label`、`aria-label`、`aria-live`、`sr-only` |
| 移动端 | viewport、`font-size: 16px`、`min-width: 0` |

## 3. 项目二：H5 商品搜索（请求 + 防抖 + 取消）

> 覆盖：fetch、async/await、防抖、AbortController、加载/错误/空状态、DOM 渲染。
> 使用公开 API `https://dummyjson.com`，需要联网。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>商品搜索</title>

<body>
  <main class="app">
    <div class="search">
      <label class="sr-only" for="search-input" style="position:absolute;width:1px;height:1px;overflow:hidden;">
        搜索商品
      </label>
      <input
        id="search-input"
        class="search__input"
        type="search"
        placeholder="搜索商品，例如 phone"
        autocomplete="off"
      />
    </div>

    <p id="status" class="status" aria-live="polite"></p>
    <section id="products" class="products"></section>
  </main>

  <script>
    // ===== 1. 常量与 DOM =====
    const ALL_URL = 'https://dummyjson.com/products?limit=20';
    const SEARCH_URL = 'https://dummyjson.com/products/search';

    const searchInput = document.getElementById('search-input');
    const statusEl = document.getElementById('status');
    const productsEl = document.getElementById('products');

    // ===== 2. 状态 =====
    let controller = null; // 当前请求的取消控制器
    let timer = null;      // 防抖定时器

    // ===== 3. 过滤未完成请求的工具 =====

    // 防抖：停止输入 300ms 后才执行
    function debounce(fn, delay = 300) {
      return function (...args) {
        if (timer) clearTimeout(timer);
        timer = setTimeout(() => fn.apply(this, args), delay);
      };
    }

    // ===== 4. 请求数据 =====

    async function loadProducts(keyword) {
      // 取消上一次还没完成的请求，避免旧结果覆盖新结果
      if (controller) controller.abort();
      controller = new AbortController();

      statusEl.textContent = '加载中...';
      productsEl.innerHTML = '';

      try {
        const url = keyword
          ? `${SEARCH_URL}?q=${encodeURIComponent(keyword)}&limit=20`
          : ALL_URL;

        const response = await fetch(url, { signal: controller.signal });

        if (!response.ok) {
          throw new Error(`HTTP ${response.status}`);
        }

        const data = await response.json();
        renderProducts(data.products || []);
      } catch (err) {
        // 主动取消的请求不当作错误
        if (err.name === 'AbortError') return;

        statusEl.textContent = `加载失败：${err.message}`;
      }
    }

    // ===== 5. 渲染 =====

    function renderProducts(list) {
      productsEl.innerHTML = '';

      if (list.length === 0) {
        statusEl.textContent = '没有找到商品，换个关键词试试';
        return;
      }

      statusEl.textContent = `共 ${list.length} 件商品`;

      const fragment = document.createDocumentFragment();

      list.forEach((product) => {
        const card = document.createElement('article');
        card.className = 'product';

        const img = document.createElement('img');
        img.className = 'product__cover';
        img.src = product.thumbnail;
        img.alt = product.title;
        img.loading = 'lazy'; // 懒加载
        img.width = 300;
        img.height = 300;

        // 图片失败时的兜底
        img.addEventListener('error', () => {
          img.style.background = '#eee';
          img.removeAttribute('src');
        });

        const body = document.createElement('div');
        body.className = 'product__body';

        const title = document.createElement('h2');
        title.className = 'product__title';
        title.textContent = product.title;

        const price = document.createElement('p');
        price.className = 'product__price';
        price.textContent = `$${product.price}`;

        body.append(title, price);
        card.append(img, body);
        fragment.appendChild(card);
      });

      productsEl.appendChild(fragment);
    }

    // ===== 6. 事件 =====

    const handleInput = debounce(() => {
      const keyword = searchInput.value.trim();
      loadProducts(keyword);
    }, 300);

    searchInput.addEventListener('input', handleInput);

    // ===== 7. 首次加载 =====
    loadProducts('');
  </script>
</body>
</html>
```

### 讲解

- **为什么用 `AbortController`**：快速输入时会发多个请求，旧请求可能后回来，把新结果覆盖。取消旧请求可以避免竞态。
- **为什么防抖**：每输入一个字符就请求，既浪费流量又容易乱序。
- **为什么先清空列表**：简单直接；更好的做法是保留旧列表 + 顶部 loading，避免闪烁。
- **为什么用 `textContent`**：商品标题来自接口，不能直接当 HTML 插入，防 XSS。
- **错误处理**：HTTP 非 2xx、断网、超时都会进入 catch；`AbortError` 要排除。
- **空状态**：搜索无结果时给明确提示。

## 5. React 数据请求页面（补充）

> 完整 Todo 在 05 文档。这里只补一个“请求 + 搜索 + 防抖”的页面，这是业务里最常见的组合。

```jsx
import { useEffect, useState } from 'react';

// 自定义 Hook：防抖值
function useDebouncedValue(value, delay = 300) {
  const [debounced, setDebounced] = useState(value);

  useEffect(() => {
    const timer = setTimeout(() => setDebounced(value), delay);
    return () => clearTimeout(timer);
  }, [value, delay]);

  return debounced;
}

export default function ProductSearch() {
  const [keyword, setKeyword] = useState('');
  const [list, setList] = useState([]);
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState('');

  const debouncedKeyword = useDebouncedValue(keyword, 300);

  useEffect(() => {
    const controller = new AbortController();

    async function load() {
      try {
        setLoading(true);
        setError('');

        const url = debouncedKeyword
          ? `https://dummyjson.com/products/search?q=${encodeURIComponent(debouncedKeyword)}&limit=20`
          : 'https://dummyjson.com/products?limit=20';

        const res = await fetch(url, { signal: controller.signal });
        if (!res.ok) throw new Error(`HTTP ${res.status}`);

        const data = await res.json();
        setList(data.products || []);
      } catch (err) {
        if (err.name !== 'AbortError') {
          setError(err.message);
        }
      } finally {
        if (!controller.signal.aborted) {
          setLoading(false);
        }
      }
    }

    load();

    // 依赖变化时取消上一次请求
    return () => controller.abort();
  }, [debouncedKeyword]);

  return (
    <main style={{ maxWidth: 720, margin: '0 auto', padding: 16 }}>
      <input
        value={keyword}
        onChange={(e) => setKeyword(e.target.value)}
        placeholder="搜索商品"
        style={{ width: '100%', height: 44, padding: '0 16px', fontSize: 16 }}
      />

      {loading && <p>加载中...</p>}
      {error && <p style={{ color: 'red' }}>加载失败：{error}</p>}
      {!loading && !error && list.length === 0 && <p>没有找到商品</p>}

      <div style={{ display: 'grid', gridTemplateColumns: 'repeat(2, 1fr)', gap: 12, marginTop: 16 }}>
        {list.map((product) => (
          <article key={product.id} style={{ background: '#fff', borderRadius: 12, overflow: 'hidden' }}>
            <img
              src={product.thumbnail}
              alt={product.title}
              loading="lazy"
              style={{ width: '100%', aspectRatio: '1 / 1', objectFit: 'cover' }}
            />
            <div style={{ padding: 12 }}>
              <h2 style={{ fontSize: 14 }}>{product.title}</h2>
              <p style={{ color: '#ff5000', fontWeight: 700 }}>${product.price}</p>
            </div>
          </article>
        ))}
      </div>
    </main>
  );
}
```

**重点：**

- 防抖抽成 `useDebouncedValue`，组件更干净。
- `useEffect` 依赖 `debouncedKeyword`，变化才请求。
- 清理函数 `controller.abort()` 取消旧请求。
- loading/error/empty 三个状态都要有。
- `finally` 里判断是否已取消，避免对旧请求 setLoading。

## 7. 如何读一份陌生的前端代码

1. **找入口**：
   - Web：`index.html` → `main.js/main.jsx` → `App`。
   - RN：`App.js` / `index.js`。
   - 小程序：`app.json` 的 `pages` 第一项。
2. **找路由**：看 URL/路由配置，定位到页面组件。
3. **看数据流**：
   - 数据从哪来？props / state / 接口 / 全局 store。
   - 数据怎么变？事件 / dispatch / setState。
   - 数据到哪去？渲染 / 子组件 / 请求。
4. **搜索关键字**：接口路径、组件名、字段名。
5. **跑起来**：先跑通，再加 `console.log` 或断点。
6. **画图**：把组件树、数据流画出来，比读十遍代码有用。
7. **小步改**：先改文案/样式，再改逻辑，每次只改一处。

## 8. 报错字典（30 条）

### JavaScript / 浏览器

| 报错 | 常见原因 | 解决 |
|---|---|---|
| `Cannot read properties of undefined (reading 'map')` | 数据还没回来 / 不是数组 | 默认值 `?? []`、可选链、加 loading 判断 |
| `xxx is not a function` | 类型不对 / 导入错 / 拼写错 | 打印 `typeof xxx`，检查导入导出 |
| `Unexpected token '<'` | 接口返回 HTML 而不是 JSON；JSX 没配 loader | 看 Network 响应；检查接口地址；配 Babel |
| `Unexpected end of JSON input` | 响应为空 / 不是合法 JSON | 检查接口、`res.text()` 调试 |
| `Maximum call stack size exceeded` | 递归没有终止条件 / 循环引用 | 加终止条件；深拷贝用 WeakMap |
| `Uncaught (in promise)` | Promise 没有 catch | 加 `.catch` 或 `try/catch` |
| `NaN` | 类型转换失败 | 检查输入；用 `Number.isNaN` |
| `Assignment to constant variable` | 给 const 重新赋值 | 用 let，或改对象内容 |
| `Cannot access 'x' before initialization` | TDZ，let/const 提前访问 | 先声明再使用 |
| `Blocked by CORS policy` | 跨域 | 后端 CORS / 开发代理 |
| `401 Unauthorized` | 没登录 / token 过期 | 检查 token，跳登录 |
| `403 Forbidden` | 没权限 | 检查角色/权限配置 |
| `404 Not Found` | 路径错 / 后端没这个接口 | 对接口文档，看 Network URL |
| `net::ERR_CONNECTION_REFUSED` | 后端没启动 / 端口错 | 启动后端，检查地址 |
| `Mixed Content` | HTTPS 页面请求 HTTP | 接口换成 HTTPS |
| `413 Payload Too Large` | 上传文件太大 | 压缩/分片/改后端限制 |
| `504 Gateway Timeout` | 后端/网关超时 | 查后端日志，加超时重试 |
| `Failed to fetch` | 断网 / 跨域 / 地址错 | 看 Network，检查网络和 CORS |

### React

| 报错 | 常见原因 | 解决 |
|---|---|---|
| `Each child in a list should have a unique "key"` | 列表没 key / key 重复 | 用稳定唯一 id |
| `Rendered more hooks than during the previous render` | 条件/循环里调用 Hook | Hook 移到顶层 |
| `Invalid hook call` | Hook 在组件外调用 / React 多版本 | 检查调用位置、`npm ls react` |
| `Too many re-renders` | render 里 setState / effect 死循环 | 事件里更新；检查依赖 |
| `Maximum update depth exceeded` | useEffect 里改依赖自身 | 修正依赖或加条件 |
| `Objects are not valid as a React child` | 直接渲染对象 | 渲染 `obj.name` 或 JSON |
| `Cannot update a component while rendering a different component` | render 期间 setState | 放到 effect/事件里 |
| `Hydration failed` | SSR 前后 HTML 不一致 | 检查随机数/日期/浏览器 API |

### React Native

| 报错 | 常见原因 | 解决 |
|---|---|---|
| `Unable to resolve module` | 依赖没装 / 路径错 | `npm i`，检查相对路径 |
| `Network request failed` | 网络 / HTTP / ATS | 用 HTTPS；检查权限和配置 |
| `VirtualizedLists should never be nested` | FlatList 套 ScrollView | 用 ListHeader/ListFooter |
| `Invariant Violation` | 组件用法错 / 原生模块没链好 | 看完整报错，重装 Pod/Gradle |
| `Cannot read property 'x' of undefined` | 数据未加载 | 默认值 + 条件渲染 |

### 小程序

| 报错 | 常见原因 | 解决 |
|---|---|---|
| `request:fail url not in domain list` | 域名没配置 | 公众平台配置合法域名；开发工具可临时关闭校验 |
| `wx.navigateTo:fail page is not found` | 路径错 / 没在 app.json 注册 | 检查 pages 和路径 |
| `switchTab:fail can not switch to no-tabBar page` | 用 switchTab 跳非 tabBar 页 | 改用 navigateTo |
| `setData 数据量过大` | 一次传太多数据 | 分页、路径更新、只传变化 |
| `Cannot read property 'dataset' of undefined` | 事件对象用错 | 用 `e.currentTarget.dataset` |
| `Component is not found` | 组件没注册 / 路径错 | usingComponents 配置 |

### 构建 / CSS

| 报错 | 常见原因 | 解决 |
|---|---|---|
| `Module not found: Can't resolve 'xxx'` | 路径/依赖/别名错 | 检查路径、安装依赖、配 alias |
| `You may need an appropriate loader` | 缺 loader | 配 css-loader/babel-loader 等 |
| `z-index` 不生效 | 没定位 / 父级层叠上下文 | 加 position；检查 transform/opacity |
| Flex 省略号不生效 | 子项 `min-width: auto` | 加 `min-width: 0` |
| 移动端 1px 很粗 | 高清屏 | 伪元素 + transform scale |
| 页面横向滚动 | 固定宽度/负 margin/100vw | 检查宽度，加 `overflow-x: hidden` 临时定位 |

## 9. 调试的标准流程

```text
1. 复现：稳定复现，记录操作步骤和输入
2. 读错：第一行错误 + 调用栈里自己的文件
3. 定位：报错行是哪个变量？打印它
4. 假设：最可能的原因是什么？
5. 验证：改一处，跑一次
6. 缩小：删掉无关代码，做最小复现
7. 修复：修根因，不是绕过
8. 回归：正常路径 + 边界 + 相关功能
9. 记录：错题本：现象 → 原因 → 修法
```

### 常用手段

```js
console.log('数据', data);
console.table(list);
console.time('render');
console.timeEnd('render');
debugger; // 浏览器会在这里停下
```

- Network 面板看请求 URL、状态码、响应。
- Sources 断点看作用域。
- React DevTools 看 props/state/重渲染。
- RN Dev Menu 看元素边界、性能监视器。
- 小程序 AppData 看当前页面 data。
